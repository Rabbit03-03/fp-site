# 〇〇FPオフィス ホームページ

全国の40〜50代の社長向け、東京・京橋の独立系FP（株式会社DSK）のサイトです。GitHub Pages で `docs/` を公開しています。

## 更新のしかた

1. `src/` の `*.body.html` を編集する（先頭コメントの title / description が検索結果に出ます）
2. `python3 build.py` を実行すると `docs/` が作り直されます
3. コミットして push すると数分で公開サイトに反映されます

黄色で表示される `<span class="todo">` は、差し替えが必要な仮の情報です。
