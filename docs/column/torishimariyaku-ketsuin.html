取締役が社長1人の会社で社長が亡くなったら？会社が止まる理由と新しい取締役の選び方

公開：2026年11月9日更新：2026年11月9日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 取締役が社長1人だけの会社では、社長が亡くなると会社を代表する人がいなくなります。契約や手続き、役員退職金を決める株主総会も、動かす人がいません。
  • 新しい取締役は株主総会で選びます。相続した株式は遺産分割までは相続人の共有になり、議決権を使うには権利行使者を1人決めて会社に通知する必要があります。
  • 役員の変更登記は2週間以内が期限です。取締役を複数にする、後継者を決める、遺言を書く、保険で資金を用意する。この4つを元気なうちに準備しましょう。

「取締役は自分だけ。株も全部自分が持っている」。小さな会社では、ごく普通の形です。

ふだんは決定が早く、困ることはありません。ところが社長に万一のことがあると、会社を動かす人が誰もいない状態になります。何が止まり、家族は何をすればよいのか。順番に見ていきます。

社長が亡くなると、会社で何が止まるか

会社と取締役の関係は、民法の「委任」のルールに従います（会社法330条）。委任は、委任した人か受けた人が亡くなると終わります（民法653条）。つまり、社長が亡くなった時点で取締役ではなくなります。

会社を代表するのは取締役です（会社法349条）。取締役が社長1人なら、代わりに会社を代表できる人がいません。

任期満了や辞任で取締役がいなくなった場合は、後任が就くまで前の取締役が役目を続けるルールがあります（会社法346条1項）。しかし、このルールは任期満了と辞任のときのものです。亡くなった場合には頼れません。

場面起きること
預金・お金の手続き会社を代表して銀行の手続きをする人がいない
契約新しい契約や更新に、会社として署名できる人がいない
株主総会株主総会を招集するのは取締役（会社法296条3項）。招集する人がいない
役員退職金役員の報酬等は、定款に定めがなければ株主総会の決議で決める（会社法361条1項）。支給の決議ができない
登記役員の変更登記を申請する代表者がいない

会社の預金口座が実際にどう扱われるかは、社長が亡くなったら会社の口座はどうなるかの記事でまとめています。死亡退職金の決め方は社長の死亡退職金と弔慰金の記事をご覧ください。

相続人が新しい取締役を選ぶ流れ

取締役は、株主総会の決議で選びます（会社法329条1項）。社長が株を持っていた場合、その株は相続人に引き継がれます。新しい取締役を選ぶのは、株主になった相続人です。

ただ、株主総会を招集するはずの取締役がいません。そこで使える方法が2つあります。

方法中身向いている場面
書面による決議株主が「○○を取締役に選ぶ」と提案し、議決権を持つ株主全員が書面か電磁的記録で同意すると、決議があったものとみなされる（会社法319条1項）相続人の意見がそろっている
一時取締役の選任利害関係人が裁判所に申し立て、裁判所が一時的に取締役の職務を行う人を選ぶ（会社法346条2項）意見がそろわない、総会を開けない

どちらの方法でも、まず「誰がその株の議決権を使うか」が決まっていないと進みません。次の章で説明します。

株式は相続人の共有に：権利行使者を決める

相続人が複数いると、相続財産は遺産分割までは相続人全員の共有になります（民法898条1項）。株式のように所有権以外の財産を共有することを「準共有」といい、共有のルールが使われます（民法264条）。

  • 共有の株式で権利を使うには、相続人が権利行使者を1人決め、その氏名を会社に通知する（会社法106条）
  • 議決権の使い方は、特段の事情がなければ持分の価格の過半数で決める（最高裁 平成27年2月19日判決）
  • 通知がないまま会社が同意しても、共有のルールに従っていない議決権の使い方は適法にならない（同判決）

相続人どうしの意見が分かれると、権利行使者が決まらず、取締役も選べません。会社が止まる期間が長くなります。くわしくは自社株が相続人の共有になったときの議決権と権利行使者の記事で解説しています。

取締役が社長1人の会社は、万一のときの手順を家族と共有しておくと安心です。会社の形と株の持ち方を一緒に確認します。

役員変更登記の期限

登記した事項に変更が生じたときは、2週間以内に本店所在地で変更の登記をします（会社法915条1項）。取締役が亡くなった場合も、新しい取締役が就いた場合も、役員の変更登記が必要です。

期限内に登記を申請しないと、代表取締役が100万円以下の過料に処される可能性があります（会社法976条、法務省の案内）。取締役が社長1人の会社では、新しい取締役を早く決めることが、登記の面でも大切です。

一時取締役（仮取締役）の選任申立て

新しい取締役を株主総会で選べないときは、裁判所に一時取締役の選任を申し立てます。大阪地方裁判所の案内をもとにまとめると、次のとおりです。

項目内容
申し立てる人利害関係人（取締役、株主、監査役、従業員、債権者など）
条件役員が欠けたこと、選任の必要があると認められること
申立先本店所在地を管轄する地方裁判所
費用申立手数料 収入印紙1,000円、郵便切手、選任登記の嘱託手数料 収入印紙3万円。予納金は事案で異なり、高額になる見込みの場合もある
選ぶ人原則として裁判所が適任者を選ぶ
登記裁判所書記官が登記を嘱託する

株主総会で後任を選べる場合は、必要性がないとされることがあります。一時取締役は、あくまで最後の手段と考えましょう。

元気なうちにできる4つの備え

  1. 取締役を複数にする

    取締役が2人以上いれば、1人が亡くなっても残った取締役が会社を代表し、株主総会を招集できます。補欠の役員をあらかじめ選んでおく方法もあります（会社法329条3項）。

  2. 後継者を決めておく

    誰に会社を任せるかを家族と共有しておくと、相続人の意見がそろいやすくなります。

  3. 遺言で株の行き先を決める

    遺言で自社株を後継者に渡すと決めておくと、遺産分割で株が宙に浮く期間を短くできます。種類と注意点は社長こそ遺言書をの記事で解説しています。

  4. 保険で資金を用意する

    会社が止まる間の運転資金、死亡退職金の財源、相続人の納税資金を、保険で準備しておく方法があります。

まず、今の会社の登記簿で取締役の人数と任期を確認してみてください。会社の現状は1分でできる無料診断でも整理できます。

よくある質問

社長が亡くなったら、任期が残っていても取締役ではなくなるのですか？

はい。会社と取締役の関係は委任のルールに従い、委任は亡くなると終わります（会社法330条、民法653条）。任期満了や辞任のときのように、後任が就くまで役目を続けるルール（会社法346条1項）も使えません。

相続人が1人だけなら、すぐに新しい取締役を選べますか？

相続人が1人なら株式は共有にならず、その相続人が株主として議決権を使えます。株主が全員同意する書面による決議（会社法319条1項）で取締役を選ぶことも考えられます。具体的な手続きは司法書士にご確認ください。

役員変更登記の期限を過ぎたらどうなりますか？

登記は変更から2週間以内に申請します（会社法915条1項）。怠ると、代表取締役が100万円以下の過料に処される可能性があります。期限を過ぎても、気づいた時点で早めに申請しましょう。
