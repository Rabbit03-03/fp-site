源泉所得税の納期の特例とは？年2回納付の条件・申請書・遅れたときの加算税

公開：2026年10月27日更新：2026年10月27日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 源泉所得税は原則、給与などを払った月の翌月10日までに納めます。給与の支給人員が常時10人未満の会社は、承認を受けると7月10日と翌年1月20日の年2回にまとめられます。
  • 特例の対象は給与・退職手当と、税理士・弁護士・司法書士などの報酬です。申請書を出した月の翌月末日までに通知がなければ承認されたものとされます。
  • 期限に遅れると不納付加算税や延滞税がかかることがあります。半年分を一度に払うので、預かった税金は別に取り分けておくと安心です。

会社が社員や役員に給与を払うときは、所得税を差し引いて（源泉徴収して）、会社が代わりに国へ納めます。

この納付は原則として毎月です。小さな会社にとっては手間が大きいため、年2回にまとめられる「納期の特例」という制度があります。条件と手続き、注意点を順に説明します。

原則と特例の納付期限

原則納期の特例
納付の回数毎月（年12回）年2回
1月〜6月に支払った分支払った月の翌月10日7月10日
7月〜12月に支払った分支払った月の翌月10日翌年1月20日
使える会社すべて給与の支給人員が常時10人未満で、税務署の承認を受けた会社

期限が土曜日・日曜日・祝日などに当たるときは、その翌日（休日明け）が期限になります。

納める税額がない月や期間でも、所得税徴収高計算書（納付書）は税務署に提出します。e-Taxで送ることもできます。

令和9年分以後は、防衛特別所得税もあわせて納付の対象になります。出典：国税庁 No.2505 源泉所得税及び復興特別所得税の納付期限と納期の特例、国税庁 令和8年版 源泉徴収のしかた

特例を使える会社と対象になる所得

「常時10人未満」の数え方

人数は、給与の支払を受ける人の平常の状態で判定します。役員も給与（役員報酬）を受けていれば数に入ります。

  • 繁忙期だけ臨時で人を雇う場合は、その臨時の人数を含めずに判定します。
  • 建設業などで日雇いの人を雇うのが常態になっている場合は、日雇いの人も含めて判定します。常雇いが10人未満でも、合計で10人以上なら使えません。

対象になる所得・ならない所得

区分支払の例
特例の対象社員の給与・賞与、役員報酬、退職手当（退職金）
特例の対象弁護士・税理士・司法書士など、特定の資格を持つ人への報酬・料金（所得税法204条1項2号）
特例の対象外原稿料・講演料、外交員報酬など、上記以外の報酬・料金

対象外の報酬・料金を払ったときは、特例の承認を受けていても、原則どおり支払った月の翌月10日までに納めます。半年まとめて納めるつもりで放置しないよう注意してください。

出典：国税庁 質疑応答事例「給与等の支払を受ける者が常時10人未満であるかどうかの判定」、国税庁 令和8年版 源泉徴収のしかた（源泉徴収制度の概要）、国税庁 No.2792 源泉徴収が必要な報酬・料金等とは

役員報酬や退職金の支払時期と、納付のタイミングを合わせた資金計画を一緒に考えます。

申請書の出し方と承認の時期

  1. 人数を確認

    給与の支給人員が常時10人未満かを確かめます。

  2. 申請書を出す

    「源泉所得税の納期の特例の承認に関する申請書」を税務署へ。

  3. 承認

    翌月末日までに通知がなければ承認されたものとされます。

  4. 年2回納付

    翌々月の納付分から特例が始まります。

書類源泉所得税の納期の特例の承認に関する申請書
提出先給与の支払事務所などの所在地を所轄する税務署長
提出方法e-Tax、または書面で持参・送付
提出時期特に定めなし（いつでも出せる）
承認の時期提出した月の翌月末日までに承認・却下の通知がなければ、翌月末日に承認されたものとされる
適用の始まり提出した月の翌月に源泉徴収する分から（納付でいうと翌々月の納付分から）

国税庁は次の例を示しています。2月中に申請書を出した場合です。

  • 2月に支払った給与の分：3月10日までに納付（まだ原則どおり）
  • 3月〜6月に支払った分：7月10日までにまとめて納付

社員が増えて常時10人以上になったときは、「源泉所得税の納期の特例の要件に該当しなくなったことの届出書」を出します。出した日が属する特例期間から承認の効力がなくなり、毎月の納付に戻ります。

出典：国税庁 A2-8 源泉所得税の納期の特例の承認に関する申請、国税庁 No.2505

納付が遅れたときの不納付加算税と延滞税

源泉所得税を期限までに納めないと、本来の税額に加えて次のような負担が生じることがあります。

負担内容
不納付加算税納税の告知を受けた場合は税額の10%。調査などで告知を予知する前に自分で納めた場合は5%
不納付加算税が
かからない場合		正当な理由がある場合や、法定納期限から1か月以内にされた一定の期限後納付の場合
延滞税法定納期限の翌日から納付する日までの日数に応じてかかる。令和8年の割合は、納期限の翌日から2か月以内が年2.8%、2か月を過ぎると年9.1%

「正当な理由」は、災害や交通の途絶など、会社に責任のない場合に限られます。法令の思い違いや計算の誤りは、正当な理由に当たりません。

年2回の納付は回数が少ない分、うっかり忘れやすくなります。7月10日と1月20日は、決算や賞与の時期と重ならないかも含めて、予定表に入れておきましょう。

出典：財務省 加算税の概要、国税庁 源泉所得税の不納付加算税の取扱いについて（事務運営指針）、国税庁 No.9205 延滞税について

役員報酬・役員退職金を払った期と資金繰りの注意

納期の特例は「納付をまとめる」制度で、税額そのものが減るわけではありません。半年分が一度に出ていくため、次のような点に気をつけます。

よいところ

  • 納付の手間が年12回から年2回に減る
  • 納付までの間、手元資金に余裕ができる
  • 小さな会社の事務負担が軽くなる

注意点

  • 半年分をまとめて払うので、1回の金額が大きい
  • 預かった税金を運転資金に使ってしまいやすい
  • 対象外の報酬は毎月納付のまま

役員報酬・役員賞与を払った期

社長の役員報酬は社員の給与より高いことが多く、源泉徴収する税額も大きくなります。役員報酬を増額した年や、事前確定届出給与などの役員賞与を払った期は、次の納付額がふくらみます。役員報酬の決め方は役員報酬の決め方の記事で解説しています。

役員退職金を払った期

役員退職金も特例の対象です。たとえば1月〜6月に退職金を払うと、その源泉所得税は7月10日にまとめて納めます。退職金は金額が大きいため、源泉徴収する税額も一度に大きくなりがちです。退職所得の計算は退職所得控除の記事をご覧ください。

資金繰りの工夫

  • 給与を払うたびに、源泉徴収した額を納税用の口座に移しておく
  • 資金繰り表の7月と1月に、納付額をあらかじめ入れておく
  • 法人税や消費税の中間納付、賞与の支給と同じ月に重ならないか確認する

源泉所得税は会社のお金ではなく、社員や役員から預かっているお金です。経費になる税金・ならない税金の整理は租税公課の経理の記事で説明しています。

決算書を見ながら、会社と社長個人にお金を残す方法を一緒に考えます。オンラインで60分、初回は無料です。全国どこからでもご利用いただけます。

よくある質問

申請書はいつ出せばよいですか？

提出時期の定めはなく、いつでも出せます。提出した月の翌月末日までに承認・却下の通知がなければ承認されたものとされ、翌々月の納付分から年2回の納付になります。

税理士への報酬も年2回の納付にまとめられますか？

税理士・弁護士・司法書士など、所得税法204条1項2号に当たる報酬・料金はまとめられます。原稿料や講演料など、それ以外の報酬・料金は原則どおり翌月10日までに納めます。

社員が10人以上になったらどうなりますか？

「源泉所得税の納期の特例の要件に該当しなくなったことの届出書」を税務署に出します。出した日が属する特例期間から承認の効力がなくなり、毎月の納付に戻ります。
