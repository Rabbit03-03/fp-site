役員退職金を書面決議（みなし決議）で決める方法：株主全員の同意・議事録・損金の時期

公開：2026年11月19日更新：2026年11月19日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 議決権を持つ株主全員が、提案に書面または電磁的記録で同意すれば、株主総会を開かなくても決議があったものとみなされます（会社法319条1項）。一人でも同意しなければ使えません。
  • 書面決議でも議事録は作ります。書くのは「決議があったとみなされた事項の内容」「提案者の氏名」「みなされた日」「議事録を作った取締役の氏名」の4つです（会社法施行規則72条4項1号）。
  • 会社の損金にする年度は、原則として決議で額が具体的に確定した日の事業年度です。役員退職金の額は登記事項ではないので、退職金の決議だけなら登記は要りません。

株主が社長一人、または社長と家族だけという会社では、株主総会を実際に開くことはあまりありません。

それでも役員退職金は、株主総会の決議が必要です。そこで使えるのが書面決議（みなし決議）です。この記事では、書面決議の要件と、同意書・議事録のそろえ方に絞って説明します。議事録の一般的な書き方は役員退職金の議事録の書き方をご覧ください。

書面決議とは：開催する総会との違い

取締役の報酬等は、定款に定めがなければ株主総会の決議で決めます（会社法361条1項）。役員退職金もこの決議をとるのが基本です。

株主総会の決議のとり方は、次の3つがあります。

通常の総会招集手続の省略（300条）書面決議（319条）
総会を開くか開く開く開かない
招集通知必要株主全員の同意で省略不要
可決の条件原則、出席株主の議決権の過半数同左議決権を持つ株主全員の同意
議事録作成（318条）作成（318条）作成（施行規則72条4項）

書面決議は、取締役または株主が議題について提案し、議決権を行使できる株主全員が同意したときに、その提案を可決する決議があったものとみなす仕組みです。

出典：e-Gov法令検索 会社法（300条・318条・319条・361条）

株主全員の同意が要る

書面決議は「過半数」ではなく全員の同意が条件です。一人でも反対、または返事がなければ成立しません。

使いやすい会社・使いにくい会社

株主の状況書面決議
社長一人が全株を持つ（一人会社）社長の同意だけでそろう。最も使いやすい
社長と配偶者・子だけ家族全員の同意書をそろえれば使える
親族以外の株主や、疎遠な親族株主がいる全員の同意がそろわなければ使えない。通常の総会で決める
  • 退任する社長自身が株主なら、社長本人の同意も必要です。
  • 「全員」を確かめるには、株主名簿が正しいことが前提です。相続で株主が変わったのに名義書換えがまだ、という会社は先に整えましょう。手続きは相続した自社株の名義書換えと株主名簿で解説しています。
  • 株主全員が同意した書面は、みなされた日から10年間、本店に備え置きます（会社法319条2項）。株主と債権者は閲覧を求められます（同条3項）。

定時株主総会の議題すべてを書面決議で可決したときは、そのときに定時株主総会が終わったものとみなされます（会社法319条5項）。決算承認と退職金を同じ書面決議で決めることもできます。

出典：e-Gov法令検索 会社法（319条）

株主構成を見ながら、書面決議で進められるか、総会を開くべきかを一緒に整理します。

提案書・同意書・議事録のそろえ方

  1. 提案書を作る

    取締役（または株主）が、支給額・時期・方法を書いた提案書を株主全員に送ります。

  2. 同意書を集める

    株主全員から、提案に同意する書面（または電磁的記録）を受け取ります。

  3. 議事録を作る

    施行規則72条4項1号の4項目を書いた議事録を作ります。

  4. 保管と支給

    同意書と議事録を10年間本店に置き、決めたとおりに支給します。

書面決議の議事録に書く事項

項目退職金での書き方の例
決議があったとみなされた事項の内容退任取締役〇〇〇〇氏に退職慰労金 金〇〇〇〇万円を、令和〇年〇月〇日に一括して振込で支給する
提案をした者の氏名または名称代表取締役 〇〇〇〇
決議があったとみなされた日令和〇年〇月〇日
議事録の作成に係る職務を行った取締役の氏名代表取締役 〇〇〇〇

開催する総会の議事録と違い、日時・場所や出席者、議事の経過は書きません。その代わり、提案の内容と「みなされた日」がはっきり分かるようにします。

  • 提案書・同意書・議事録で、支給額や支給日の記載をそろえます。
  • 同意書には、株主の氏名と同意した日付を入れておくと、みなされた日の説明がしやすくなります。
  • 金額の決め方そのもの（功績倍率など）は役員退職金の相場と適正額の決め方、規程の作り方は役員退職金規程の作り方をご覧ください。

出典：e-Gov法令検索 会社法施行規則（72条）

取締役会の書面決議（370条）

株主総会で「規程に従い、具体的な額・時期・方法は取締役会に一任する」と決めた場合、金額は取締役会で決めます。この取締役会も書面決議にできますが、条件があります。

株主総会の書面決議取締役会の書面決議
根拠会社法319条会社法370条
定款の定め不要必要
同意する人議決権を行使できる株主全員議決に加わることができる取締役全員
ほかの条件なし監査役設置会社では、監査役が異議を述べないこと
議事録の事項施行規則72条4項1号施行規則101条4項1号（内容・提案した取締役・みなされた日・作成した取締役）
備置き同意書面を10年（319条2項）、議事録を10年（318条）議事録と同意書面を10年（371条1項）

定款に370条の定めがなければ、取締役会は実際に開く必要があります。まず定款を確認しましょう。取締役会を置いていない会社では、この手順は関係ありません。

出典：e-Gov法令検索 会社法（370条・371条）、e-Gov法令検索 会社法施行規則（101条）

損金にする時期と登記

会社の損金にする事業年度

原則認められている方法
損金にする年度株主総会の決議等で額が具体的に確定した日の事業年度実際に支払った事業年度
条件決議で額が確定していること支払った額を損金経理すること

書面決議では、総会の日の代わりに「決議があったとみなされた日」が基準になります。決算日の前後どちらで同意がそろうかで、損金にする年度が変わることがあります。額が確定する前の年度に、内定額を未払金に計上しても損金にはなりません。

受け取る役員の側では、決議の日（決議が支給することだけで金額を決めていないときは、金額が具体的に決まった日）が退職所得の収入すべき時期になります。

決算期と退任時期の組み合わせは社長の退職時期と決算期の考え方にまとめています。

出典：国税庁 No.5208 役員の退職金の損金算入時期、国税庁 法人税基本通達 9-2-28、国税庁 No.2728 退職所得の収入金額の収入すべき時期

登記は要るか

株式会社の登記事項（会社法911条3項）には、取締役の氏名などはありますが、役員の報酬や退職慰労金は入っていません。退職金を決めただけなら登記はしません。

ただし、同じ書面決議で取締役の退任や後任の選任も決めた場合、その役員変更は登記が必要です。書面決議による決議を登記に使うときは、議事録の代わりに、みなし決議に当たることを証する書面を申請書に添付します（商業登記法46条3項）。社長交代の手続き全体は社長交代の手続き一覧をご覧ください。

出典：e-Gov法令検索 会社法（911条）、e-Gov法令検索 商業登記法（46条）

よくある質問

株主が社長一人の会社でも、議事録は必要ですか？

必要です。書面決議で株主総会の決議があったとみなされた場合も、決議があったとみなされた事項の内容、提案者の氏名、みなされた日、議事録を作った取締役の氏名を書いた議事録を作ります（会社法施行規則72条4項1号）。

株主のうち一人だけ同意が取れない場合は？

書面決議は議決権を行使できる株主全員の同意が条件なので使えません。通常どおり株主総会を招集して決議します。

取締役会も書面で済ませられますか？

定款に会社法370条の定めがあれば、議決に加われる取締役全員の同意で書面決議にできます。監査役設置会社では監査役が異議を述べないことも条件です。定款に定めがなければ取締役会を開きます。
