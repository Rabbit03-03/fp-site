サイバー攻撃と中小企業の備え｜被害で出るお金とまずやること

公開：2026年11月14日更新：2026年11月14日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 警察庁によると、令和7年上半期のランサムウェア被害116件のうち77件が中小企業でした。約3分の2を占め、件数・割合とも過去最多です。
  • 調査・復旧に1,000万円以上かかった組織は59%。止まっている間の売上減や、取引先・顧客への賠償も重なります。
  • まずはIPAの「SECURITY ACTION」の6か条から。対策で防ぎきれない分のお金は、サイバー保険と手元資金で備えます。

「うちは小さい会社だから狙われない」。そう考える社長は少なくありません。

しかし公式の統計を見ると、ランサムウェア被害の中心はむしろ中小企業です。この記事では、数字で現状を確認し、被害で出るお金と、今日から始められる備えを整理します。

統計で見る中小企業の被害

ランサムウェアは、会社のデータを暗号化して使えなくし、元に戻す代わりに金銭を要求する攻撃です。警察庁の公表から、主な数字をまとめました。

項目数字
被害報告件数（令和6年）222件
被害報告件数（令和7年上半期）116件（半期として令和4年下半期と並び最多）
うち中小企業（令和7年上半期）77件、全体の約3分の2（件数・割合とも過去最多）
調査・復旧費用が1,000万円以上の組織令和6年 50% → 令和7年上半期 59%
侵入経路VPNやリモートデスクトップ用の機器からが8割以上

令和7年の1年間では、国内で226件の被害が認知されています。テレワーク用の機器の弱点を突かれる例が多いのも特徴です。

IPAの「情報セキュリティ10大脅威 2026」でも、組織向けの1位は「ランサム攻撃による被害」、2位は「サプライチェーンや委託先を狙った攻撃」でした。取引先の大企業に入るための入口として、中小企業が狙われることもあります。

被害で出るお金は3種類

サイバー攻撃の被害は、パソコンを直せば終わりではありません。お金の面では、大きく3つに分かれます。

種類中身
調査・復旧費原因と被害範囲の調査、システムやデータの復旧、機器の入れ替え、弁護士などの専門家費用
休業による損失受注・出荷・会計が止まる間の売上減。その間も人件費や家賃などの固定費は出ていく
賠償・対応費顧客や取引先への損害賠償、情報漏えいのお知らせやお詫び、問い合わせ窓口の費用

警察庁の令和6年の集計では、調査・復旧に1か月以上かかった組織が49%ありました。1か月止まると、1か月分の固定費を売上なしで払うことになります。

IPAの中小企業向け調査（2024年度、4,191社）でも、被害額の最大が1億円という回答がありました。一方で、情報セキュリティ対策への投資を「していない」「わからない」と答えた企業は約7割です。

個人データの漏えいでは、法律上の手続きも必要です。不正アクセスによる漏えいのおそれがあれば、個人情報保護委員会への報告が義務になります。

報告期限（発覚日から）
速報3〜5日以内
確報30日以内（不正の目的で行われたおそれがある場合は60日以内）

報告の対象は、要配慮個人情報を含む漏えい、財産的被害のおそれがある漏えい、不正の目的によるおそれがある漏えい、本人の数が1,000人を超える漏えいです。出典：IPA 2024年度中小企業における情報セキュリティ対策に関する実態調査（概要説明資料）、個人情報保護委員会 漏えい等の対応とお役立ち資料

売上が止まったとき会社が何か月もつかは、BCPとお金の備えの記事で計算方法を説明しています。

会社が1か月止まったら、いくら必要か。固定費と借入返済から一緒に計算します。

まずやること：SECURITY ACTION

IPAの「SECURITY ACTION」は、中小企業が情報セキュリティ対策に取り組むことを自ら宣言する制度です。審査や認定ではなく、ロゴマークは無料で使えます。

一つ星二つ星
取り組むこと「情報セキュリティ6か条」に取り組む「5分でできる！情報セキュリティ自社診断」で現状を把握し、基本方針を定めて外部に公開する
位置づけ対策を始める前でも宣言できる組織的な取り組みを始めたことの宣言

一つ星の「6か条」は次のとおりです。

  1. OSやソフトウェアは常に最新の状態にしよう
  2. ウイルス対策ソフトを導入しよう
  3. パスワードを強化しよう
  4. 共有設定を見直そう
  5. バックアップを取ろう
  6. 脅威や攻撃の手口を知ろう

侵入経路の8割以上がVPNなどの機器だったことを考えると、1番目の「最新の状態に」は特に大切です。バックアップは、ネットワークから切り離した場所にも保管しておくと、暗号化の被害を受けにくくなります。

宣言は、一部の補助金・助成金で申請の要件にもなっています。宣言した場合の表記は「認定を受けた」ではなく「宣言した」です。

サイバー保険で備える考え方

対策をしても、攻撃を完全に防ぐことはできません。防ぎきれなかったときのお金は、保険と手元資金で備えます。

サイバー保険は、サイバー攻撃や情報漏えいで会社が負う損失を補償する損害保険の一般的な名称です。補償の中身は契約によって違うため、次の3つが入っているかを確認します。

  • 賠償：顧客や取引先から損害賠償を求められたとき
  • 対応費用：調査・復旧、お知らせやお詫び、専門家への相談など
  • 休業の損失：システムが止まっている間の利益の減少

考え方の順番は、次のとおりです。

  1. 止まったときの1か月あたりの固定費と借入返済を出す
  2. 手元資金で何か月もつかを確かめる
  3. 足りない分と、賠償のように金額が読めない分を保険で手当てする

今の火災保険や賠償責任保険に、サイバーの補償が一部付いていることもあります。重複や漏れがないよう、まとめて見直すのがおすすめです。会社の損害保険の見直し方は損害保険の経理と見直しの記事で、社長に万一のときに会社に必要なお金は事業保障の必要保障額の記事や必要保障額の無料ツールで確認できます。

決算書を見ながら、会社と社長個人にお金を残す方法を一緒に考えます。オンラインで60分、初回は無料です。全国どこからでもご利用いただけます。

よくある質問

社員数人の小さな会社でも狙われますか？

警察庁の集計では、令和7年上半期のランサムウェア被害116件のうち77件が中小企業で、約3分の2を占めました。会社の規模にかかわらず、VPN機器などの弱点を探して侵入する手口が多く見られます。

SECURITY ACTIONは費用がかかりますか？

自ら宣言する制度で、ロゴマークは無料で使えます。IPAによる審査や認定はありません。一部の補助金・助成金では申請の要件にもなっています。

サイバー保険に入れば対策はしなくてよいですか？

保険は被害が出たあとのお金を補う手段で、被害そのものは防げません。まず6か条などの対策をして、防ぎきれない分を保険と手元資金で備える順番がおすすめです。
