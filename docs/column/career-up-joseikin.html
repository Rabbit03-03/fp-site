キャリアアップ助成金（正社員化コース）の流れと支給額：パート・有期社員を正社員にするとき

公開：2026年11月23日更新：2026年11月23日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 有期・パートの社員を正社員にすると、中小企業は1人あたり最大80万円（重点支援対象者の有期雇用労働者）を受けられます（令和8年度）。
  • 転換の前日までに「キャリアアップ計画」を労働局に出し、就業規則に転換制度を書いておくことが前提です。後からでは間に合いません。
  • 転換後6か月の賃金を、転換前6か月より3%以上増やして支払い、支払日の翌日から2か月以内に申請します。

長く働いてくれているパートや契約社員を、正社員にしたい。そんなときに使えるのが、厚生労働省の「キャリアアップ助成金（正社員化コース）」です。

ただし、順番を間違えると1円も受けられません。この記事では、令和8年度の内容をもとに、流れと支給額、つまずきやすい点をまとめます。

支給額はいくら？（令和8年度・中小企業）

中小企業の場合、1人あたりの支給額は次のとおりです。重点支援対象者は、第1期と第2期の2回に分けて支給されます。

転換前重点支援対象者それ以外
有期雇用労働者80万円（第1期40万円＋第2期40万円）40万円（第1期のみ）
無期雇用労働者40万円（第1期20万円＋第2期20万円）20万円（第1期のみ）

このほか、条件を満たすと1事業所あたり1回だけ、次の加算があります（中小企業の額）。

加算の内容加算額
正社員転換制度を新たに規定し、その区分に転換した20万円
多様な正社員制度（勤務地限定・職務限定・短時間正社員のいずれか）を新たに規定し、転換した40万円
正社員への転換に関する情報を自社サイトか「しょくばらぼ」で公表した20万円

申請できる人数は、1年度1事業所あたり20人までです（同じ人の2回目の申請は数えません）。

大企業は額が異なります。中小企業は、資本金か常時雇用する労働者数のどちらかが基準以下の会社です（小売業5,000万円以下・50人以下、サービス業5,000万円以下・100人以下、卸売業1億円以下・100人以下、その他3億円以下・300人以下）。出典：厚生労働省 キャリアアップ助成金のご案内（令和8年度版）

重点支援対象者とは

次のどれかに当てはまる人は「重点支援対象者」となり、支給額が2倍（第1期＋第2期）になります。

区分内容
a雇い入れから3年以上の有期雇用労働者
b雇い入れから3年未満で、過去5年間に正社員だった期間が合計1年以下、かつ過去1年間に正社員として雇われていない有期雇用労働者
c派遣労働者、母子家庭の母等・父子家庭の父、人材開発支援助成金の特定の訓練を修了した人

第2期は、転換後12か月分の賃金を払ったあとに申請します。第2期の6か月の賃金を、第1期の6か月より合理的な理由なく下げていないことが条件です。第1期が不支給になると、第2期は申請できません。

正社員にしたい方の給与と人数から、助成額と人件費の増え方を一緒に試算します。

申請までの流れ

  1. 計画を出す

    転換の前日までに、キャリアアップ計画を労働局へ提出します。

  2. 規則を整える

    就業規則に正社員への転換制度を書き、周知し、監督署へ届け出ます。

  3. 正社員にする

    規則の手続（面接や試験など）どおりに転換し、賃金を3%以上上げます。

  4. 申請する

    6か月分の賃金を払った日の翌日から2か月以内に申請します。

手続期限・ポイント
キャリアアップ計画転換の実施日の前日まで。事業所ごとに作り、計画期間は3年以上5年以内。キャリアアップ管理者を選び、労働者の代表から意見を聴きます。
就業規則転換の手続、要件、時期を明記。周知した日から効力が生じます。監督署への届出は遅くとも申請までに。
第1期の申請転換後6か月分の賃金を支払った日の翌日から2か月以内
第2期の申請（重点支援対象者）転換後12か月分の賃金を支払った日の翌日から2か月以内

転換のときは、新しい労働条件を書面で示します。書き方は労働条件通知書と雇用契約書の記事をご覧ください。

主な要件

  • 転換前に、正社員と賃金の決め方が違う区分（パート・契約社員など）で、通算6か月以上雇われていること。
  • 転換後の正社員は、期間の定めがなく、勤務地や職務が限定されず、所定労働時間が他の正社員と同じであること（多様な正社員は別に扱います）。
  • 賞与か退職金の制度と、昇給が就業規則などに書かれ、実際に適用されること。昇給には客観的な基準が必要です。
  • 転換後6か月の賃金を、転換前6か月より3%以上増やすこと。原則は1時間あたりの賃金で比べます。
  • 転換後も雇用保険に加入し、申請日に離職していないこと。
  • 事業主や取締役の3親等以内の親族でないこと。新卒で雇い入れから1年たっていない人は対象外です。

3%の比較には、基本給と定額で払う手当を含めます。実費弁償的なものや、毎月の状況で変わる手当は除きます。固定残業代を減らした場合は、含めた場合と含めない場合の両方で3%以上が必要です。出典：厚生労働省 キャリアアップ助成金のご案内（令和8年度版）、厚生労働省 事業主の皆さまへ（令和8年4月8日）

パートのまま退職金を用意したい場合は、パート社員の退職金の記事も参考になります。

よくある不支給の理由

つまずきどうなるか
計画を転換後に出した計画は転換の前日までが期限です。その人の転換は対象になりません。
賞与の書き方があいまい「賞与は支給しない。ただし業績により支給することがある」のような規定は対象外です。
昇給の基準がない据え置きや降給だけの規定、基準のない昇給は対象外です。
規則が「個別の契約で定める」だけ正社員との違いが読み取れないと対象外です。
転換後に試用期間を付けた試用期間の終了日の翌日が転換日とみなされ、期限の計算がずれます。
就業規則を届け出ていない申請までに監督署へ届け出ていないと、原則不支給です。
申請期限を過ぎた賃金支払日の翌日から2か月を過ぎると申請できません。

試用期間の考え方は試用期間の決め方の記事にまとめています。

受け取った助成金は会社の収入になります。いつ、どの科目で計上するかは補助金・助成金の経理の記事をご覧ください。

要件は年度の途中で変わることがあります。取り組む前に、管轄の都道府県労働局かハローワークでご確認ください。出典：厚生労働省 キャリアアップ助成金

よくある質問

すでに正社員にしてしまった人でも申請できますか？

キャリアアップ計画は転換の実施日の前日までに出す必要があります。計画を出さずに転換した人は対象になりません。

家族を正社員にした場合も対象ですか？

事業主や取締役の3親等以内の親族は対象外です。

助成金はいつ入金されますか？

第1期は、転換後6か月分の賃金を払った日の翌日から2か月以内に申請し、労働局の審査を経て支給されます。転換からすぐに入るお金ではないため、昇給分の人件費は先に会社が負担します。
