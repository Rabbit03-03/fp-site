社長が退職した翌年の住民税はいくら？退職後に届く請求と取っておく目安

公開：2026年10月29日更新：2026年10月29日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 住民税は前年1年間の所得にかかります。退職して収入がなくなっても、在任中の役員報酬分の住民税が後から届きます。
  • 退職すると給与天引き（特別徴収）が止まり、残りは自分で納める普通徴収に切り替わります。1月1日〜4月30日の退職では、残りが最後の給与や退職金から一括で天引きされます。
  • 退職金の住民税は、ほかの所得と分けて、支払いのときに天引きされます。翌年に届く住民税とは別ものです。

社長や役員が退任した翌年の6月、思っていたより大きな住民税の納税通知書が届いて驚く方がいます。

住民税は「後払い」の税金だからです。仕組みと、退職前に取っておきたい金額の目安を説明します。

住民税は前年の所得にかかる

個人住民税の所得割は、前年1月1日〜12月31日の所得で計算されます。課税されるのは、その年の1月1日に住所がある市区町村です。

項目内容
所得割標準税率10%（市区町村民税6%、道府県民税・都民税4%）
均等割標準4,000円（市区町村民税3,000円、道府県民税1,000円）
森林環境税2024年度から均等割とあわせて1,000円
給与天引き（特別徴収）6月から翌年5月までの毎月の給与から
自分で納める（普通徴収）通常、6月・8月・10月・翌年1月の年4回

たとえば2026年に受け取った役員報酬の住民税は、2027年6月から2028年5月にかけて納めます。

つまり、2026年中に退職して収入がなくなっても、2027年6月には2026年分の役員報酬に対する住民税が届きます。

政令指定都市では、所得割の内訳が市民税8%・道府県民税2%になります。自治体によって標準と異なる税率を定めている場合があります。出典：総務省 個人住民税、東京都主税局 個人住民税、福岡市 申告、納税の方法

退職したときの切り替えと一括徴収

在任中は、会社が役員報酬から住民税を天引きして納めています（特別徴収）。退職すると天引きができなくなるため、残りの扱いは退職した時期で変わります。

退職した時期残りの住民税
6月1日〜12月31日原則、普通徴収に切り替わり、自分で納めます。本人が申し出れば、最後の給与や退職金から一括で天引きできます。
1月1日〜4月30日5月31日までに払われる給与や退職金が残りの税額を超えるときは、本人の申し出がなくても一括で天引きされます。
別の会社で引き続き働く本人が申し出れば、新しい勤務先で特別徴収を続けられます。

会社は、退職した日の翌月10日までに「給与所得者異動届出書」を、退職した役員の住所地の市区町村に出します。

1月〜4月に退職すると、最後に受け取る報酬や退職金の手取りが、一括徴収の分だけ減ります。資金計画では、この差し引きも見込んでおきます。

死亡退職の場合や、一括で徴収すべき金額が退職手当等の額を超える場合は、一括徴収の対象外です。出典：東京都主税局 特別徴収にかかる手続きについて、大阪市 退職・転勤などがあった場合

退任の時期と役員報酬の額から、退職後に届く住民税の目安を一緒に計算します。

退職金の住民税との違い

役員退職金にも住民税はかかりますが、仕組みが違います。役員報酬の住民税と混同しないよう、並べて整理します。

役員報酬の住民税退職金の住民税
いつの所得にかかるか前年の所得支払われた年（その年のうちに課税）
ほかの所得との関係ほかの所得と合算ほかの所得と分けて計算（分離課税）
税率所得割10%＋均等割所得割のみ10%（市区町村6%、道府県4%）
納め方翌年6月から天引きまたは自分で納付退職金を払うときに会社が天引き

退職金の住民税は、受け取る時点で差し引かれて終わります。翌年6月に届く住民税に、退職金の分は通常含まれません。

退職金の課税対象額は、退職所得控除を引いた後の額を2分の1にして計算します。ただし勤続5年以下の役員等は2分の1になりません。控除の計算は退職所得控除の記事、手取りの目安は退職金の手取り計算ツールで確かめられます。

出典：大阪市 退職手当等に対する市民税・府民税の特別徴収について、大阪市 課税の特例

計算例：取っておく目安

2026年3月末に退任した社長の例です。役員報酬は前年の2025年も年1,200万円だったとします。社会保険料などの所得控除の合計は、仮に200万円とします。

2025年の役員報酬12,000,000円
給与所得控除（収入850万円超は上限）－1,950,000円
所得控除（仮定）－2,000,000円
課税所得8,050,000円
所得割（10%）805,000円
均等割＋森林環境税4,000円＋1,000円
2026年6月から納める住民税の目安約810,000円

退任した後の2026年6月から、約81万円を年4回に分けて自分で納める計算です。

さらに2027年6月には、2026年1月〜3月に受け取った報酬3か月分に対する住民税が届きます。退任後の2年間は、住民税の請求が続くと考えておきます。

  1. 前年の報酬を確認

    源泉徴収票の支払金額を見ます。

  2. 課税所得を出す

    給与所得控除と所得控除を差し引きます。

  3. 10%を掛ける

    均等割と森林環境税を足します。

  4. 退任年の分も

    翌々年分も同じ式で見込みます。

住民税では調整控除などがあるため、実際の税額は少し変わります。目安として、前年の課税所得の10%を取っておくと考えると分かりやすくなります。出典：国税庁 No.1410 給与所得控除

退職前にしておきたいこと

  • 前年の源泉徴収票から、翌年6月に届く住民税の目安を出しておく
  • 1月〜4月の退任なら、最後の報酬や退職金から一括で引かれる額を確かめる
  • 退職金の手取りのうち、住民税2年分を別の口座に分けておく
  • 健康保険料も前年の所得で決まるため、あわせて見込む

退任後の健康保険は退任後の健康保険の記事、退任の時期の決め方は役員定年規程の記事で解説しています。退職金の額の目安は退職金の早見表もご利用ください。

よくある質問

退職して収入がないのに、なぜ住民税が来るのですか？

住民税の所得割は前年1年間の所得で計算され、翌年6月から納めるためです。退職した年の役員報酬分は、翌年に届きます。

退職金の住民税は、翌年に別で請求されますか？

退職金の住民税は、ほかの所得と分けて計算され、退職金を払うときに会社が天引きします。翌年の住民税とは別に、受け取る時点で納め終わります。

3月に退職すると、住民税はどうなりますか？

1月1日〜4月30日の退職では、5月31日までに払われる給与や退職金が残りの税額を超えるとき、5月分までの残りが一括で天引きされます。その後、6月からは前年分の住民税を普通徴収で納めます。
