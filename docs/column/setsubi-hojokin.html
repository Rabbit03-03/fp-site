設備投資に使える国の補助金の探し方と選び方（2026年11月時点）

公開：2026年11月16日更新：2026年11月16日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 2026年度から、ものづくり補助金と新事業進出補助金は「新事業進出・ものづくり商業サービス補助金」に一体化されました。第2回公募の締切は2026年12月25日15時です。
  • 何を買うかで選ぶ補助金が変わります。カタログにある省力化機器なら省力化投資補助金（カタログ注文型）、ソフトやITツールならデジタル化・AI導入補助金が候補です。
  • 補助金は後払いです。交付決定の前に発注した経費は対象外になり、入金は実績報告と確定検査のあとです。その間の資金は自社で用意します。

「設備を入れたいが、使える補助金はあるか」というご相談をよくいただきます。

国の補助金は名前や枠が毎年のように変わります。この記事では、2026年11月時点で公式サイトに出ている内容だけを使って、探し方と選び方、お金の流れを整理します。

以前の「ものづくり補助金」と「中小企業新事業進出補助金」は、それぞれの公式サイトで公募終了と案内されています。新しい申請は一体化した補助金で受け付けています。事業再構築補助金や新事業進出補助金を検討していた会社は、新事業進出枠が候補になります。

どの補助金も、賃上げや付加価値額の目標を含む事業計画が求められます。たとえば新事業進出・ものづくり補助金は、付加価値額の年平均成長率4.0%以上、1人あたり給与支給総額の年平均成長率3.5%以上などが基本要件です。目標に届かないと、補助金の返還を求められる場合があります。

何を買うかで選ぶ

補助金は「何を買うか」「何のために買うか」で候補が絞れます。

やりたいこと候補になる補助金
カタログに載っている省力化機器を早く入れたい省力化投資補助金（カタログ注文型）。販売事業者と一緒に申請し、交付決定は最短1か月
自社に合わせた設備やシステムで人手不足を解消したい省力化投資補助金（一般型）。審査は約3か月
新しい製品・サービスを作るための設備新事業進出・ものづくり補助金（革新的新製品・サービス枠）
新しい市場に出る。建物も必要新事業進出・ものづくり補助金（新事業進出枠）。建物費も対象
会計・受発注などのソフトやITツールデジタル化・AI導入補助金

同じ経費に複数の補助金を重ねて使えるかは、各公募要領で決められています。候補を1つに絞ってから計画を作ると、手戻りが少なくなります。

補助金と税制は別の制度です。補助金で買った設備に中小企業経営強化税制などを使うときの考え方は、中小企業経営強化税制の記事で解説しています。

設備の金額と入金までの期間から、手元資金がいくら要るかを一緒に計算します。

補助金は後払い：採択から入金までの流れ

補助金は後払いです。採択されてもすぐには入金されません。新事業進出・ものづくり補助金の流れは次のとおりです。

  1. 応募・採択

    GビズIDプライムで電子申請します。採択はまだ「交付候補」です。

  2. 交付申請・交付決定

    見積りなどを出し、交付決定を受けます。発注はここから。

  3. 発注・支払い

    実施期間内に納品・検収・支払いまで済ませます。

  4. 実績報告・入金

    確定検査で額が決まり、精算払請求のあとに振り込まれます。

押さえておきたい点は3つです。

  • 交付決定の前に発注・契約・支払いした経費は対象外です。事前着手は認められていません。
  • 補助事業の実施期間は、交付決定日から革新的新製品・サービス枠で10か月以内、新事業進出枠・グローバル枠で14か月以内です。
  • 実績報告は、補助事業の完了から30日以内（または完了期限日のどちらか早い日まで）に出します。補助事業が終わったあとも、3〜5年間、毎年の事業化状況報告が続きます。

GビズIDプライムの発行には1週間程度かかります。申請を考えた時点で取っておくと安心です。

出典：新事業進出・ものづくり商業サービス補助金 よくあるご質問、同 第2回公募要領

つなぎ資金の考え方

設備代はいったん全額を会社が払います。補助金が入るまでの数か月から1年以上、その分のお金が手元から出たままになります。

考えることポイント
いくら要るか補助金分だけでなく、設備代の全額（消費税を含む）を先に払う前提で考える
いつまで要るか実施期間の終わりから実績報告、確定検査、入金まで。月ごとに資金繰り表に書く
どう用意するか自己資金か借入れ。借りるなら採択の段階で金融機関に相談する
返せない場合に備える確定検査で補助額が減る、賃上げ目標に届かず返還を求められる、といった場合も考えておく

借入れを使う場合、信用保証協会の保証付き融資も選択肢です。しくみは信用保証協会の保証付き融資のしくみ、月ごとの見込みの立て方は資金繰り表の作り方をご覧ください。会社を引き継ぐときの補助金は事業承継・M&A補助金の記事にまとめています。

決算書を見ながら、会社と社長個人にお金を残す方法を一緒に考えます。オンラインで60分、初回は無料です。全国どこからでもご利用いただけます。

よくある質問

採択されたら、すぐに設備を発注してよいですか？

いいえ。採択のあとに交付申請をして、交付決定を受けてから発注します。交付決定の前に発注・契約・支払いした経費は補助の対象外です。

ものづくり補助金はなくなったのですか？

2026年度から、ものづくり補助金と新事業進出補助金を一体的に運用する「新事業進出・ものづくり商業サービス補助金」が始まりました。以前のものづくり補助金の公式サイトでは公募終了と案内されています。

補助金はいつ入金されますか？

補助事業が終わって実績報告を出し、確定検査で補助額が決まったあと、精算払請求を行ってから振り込まれます。それまでの設備代は会社が立て替えます。
