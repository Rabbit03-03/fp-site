うちは相続税がかかる？早見表で確かめる手順と、社長がしやすい7つの勘違い

公開：2026年11月10日更新：2026年11月10日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 早見表に入れるのは「債務を引いた財産の合計」と「配偶者の有無・子どもの人数」の2つです。出てくるのは家族全体の納税額の目安です。
  • 社長の場合、自社株の入れ忘れや、生命保険金・死亡退職金の非課税枠の引き忘れで、目安が大きくずれます。
  • 小規模宅地等の特例を使って基礎控除以下になる場合や、配偶者の税額軽減で納税額がゼロになる場合も、申告が必要です。

「うちは相続税がかかるのか、まず大まかに知りたい」。社長からよくいただくご相談です。

当サイトの相続税の早見表を使えば、数字を2つ確かめるだけで目安が分かります。ただし、入れる数字を間違えると、目安も大きくずれます。この記事では、早見表の使い方と、社長がしやすい勘違いをまとめます。

早見表で確かめる3つの手順

早見表は、何を入れると何が出るかが決まっています。

手順見るところ注意点
1. 財産の合計の行を選ぶ5,000万円から10億円まで、8つの行借入などの債務を引いた後の額で選ぶ
2. 家族構成の列を選ぶ配偶者あり・なし × 子ども1〜3人配偶者ありは、配偶者が法定相続分（2分の1）を受け取る前提
3. 交わるマスを読む家族全体が納める相続税の目安（万円）行と行の間の額は、上下の行の間と考える

たとえば財産2億円・配偶者と子ども2人なら、目安は約1,350万円です。財産5,000万円・配偶者と子ども3人なら0です。法定相続人が4人で、基礎控除が5,400万円（3,000万円＋600万円×4人）になり、財産がその範囲に収まるためです。

「配偶者あり」のマスは、配偶者の税額軽減を使った後の、家族全体の納税額です。配偶者の次の相続（二次相続）でかかる税金は含みません。

行の間の金額や、子どもが4人以上の場合、生命保険金・死亡退職金を含めて計算したい場合は、相続税かんたん試算で自分の数字を入れてください。

早見表に含まれていないもの

早見表は、計算の条件をそろえた目安です。次のものは含みません。

  • 自社株・不動産の評価（評価した後の額を、自分で財産の合計に入れる）
  • 生命保険金・死亡退職金の非課税枠
  • 小規模宅地等の特例
  • 生前贈与の加算
  • 配偶者の次の相続（二次相続）の税金

つまり、早見表に入れる「財産の合計」を正しく作れるかが、目安の精度を決めます。ここで社長がしやすい勘違いを次に見ていきます。

社長がしやすい7つの勘違い

勘違い正しくは
1. 自社株は財産に入らない非上場の株式も相続財産。国税庁のルールで評価して入れる
2. 保険金・退職金は全額入れる（または全額入れない）それぞれ「500万円×法定相続人の数」を引いた残りを入れる
3. 生前贈与は7年分を足す2026年12月31日までの相続は、原則3年以内の贈与。7年へは段階的に延びる
4. 土地は時価で入れる路線価方式または倍率方式で評価する
5. 基礎控除は家族の人数で決まる「法定相続人の数」で決まる。養子の数には制限がある
6. 借入は財産と別に考える確実な債務と葬式費用は、財産から差し引ける
7. 税額がゼロなら申告はいらない特例や配偶者の税額軽減を使うなら、申告が必要

1. 自社株を財産に入れ忘れる

上場していない自社株も、相続財産です。社長の財産の中で一番大きいこともあります。

評価は国税庁のルールで行います。同族株主が取得する場合は、会社の規模で類似業種比準方式・純資産価額方式・その併用に分かれます。資本金の額や決算書の純資産の額とは一致しません。しくみは自社株の評価の記事で解説しています。

2. 非課税枠を引く前と後を混同する

家族（相続人）が受け取る死亡保険金と死亡退職金には、それぞれ「500万円×法定相続人の数」の非課税枠があります。妻と子2人なら、法定相続人は3人で、枠はそれぞれ1,500万円です。

使うもの入れる額
早見表枠を引いた後の額を、財産の合計に足す
相続税かんたん試算受け取る額をそのまま（枠を引く前）入れる。枠はツールが自動で引く

たとえば妻と子2人で死亡保険金3,000万円なら、早見表に足すのは1,500万円です。試算ツールには3,000万円を入れます。両方で引くと、二重に引いたことになります。

相続人以外の人が受け取った分には、非課税枠はありません。死亡退職金の枠の対象は、死亡後3年以内に支給が確定したものです。

3. 生前贈与の加算を「7年」と思い込む

相続や遺贈で財産を受け取った人が、亡くなった人から暦年課税で贈与を受けていた場合、一定期間の贈与は相続財産に足し戻します。2024年1月からの改正で、この期間は3年から7年へ段階的に延びます。

亡くなった日足し戻す贈与
2026年12月31日まで亡くなる前3年以内
2027年1月1日〜2030年12月31日2024年1月1日から亡くなった日まで
2031年1月1日以後亡くなる前7年以内

延びた期間（3年より前）に受けた贈与は、合計100万円までは足し戻しません。相続時精算課税を選んだ贈与は、扱いが別です。くわしくは生前贈与の記事をご覧ください。

4. 土地を時価で入れる・特例を自動だと思う

相続税では、土地は時価ではなく、路線価がある地域は路線価方式、ない地域は固定資産税評価額に倍率をかける倍率方式で評価します。建物は固定資産税評価額と同じ額です。

自宅の土地なら、小規模宅地等の特例で330㎡まで評価額を80%減らせる場合があります。ただし、申告書に特例を受ける旨を書き、計算の明細書などを付けることが要件です。分け方が決まっていることも原則として必要です。要件は小規模宅地等の特例の記事で解説しています。

5. 基礎控除の人数を数え間違える

基礎控除は「3,000万円＋600万円×法定相続人の数」です。養子を数に入れられるのは、実子がいるときは1人、いないときは2人までです。数え方は基礎控除の記事にまとめています。

6. 借入や葬式費用を差し引き忘れる

亡くなったときにあった借入金や未払金で、確実と認められるものは差し引けます。葬式費用も差し引けます。生前に買ったお墓の未払代金など、非課税財産に関する債務は差し引けません。社長の個人保証などの扱いは債務控除の記事をご覧ください。

7. 税額がゼロなら申告はいらないと思う

申告がいるかどうかは、小規模宅地等の特例を使う前の課税価格の合計で判断します。特例を使って基礎控除以下になる場合も、申告が必要です。

配偶者の税額軽減も同じです。配偶者が受け取った財産が1億6,000万円までか法定相続分までなら配偶者の相続税はゼロになりますが、申告書の提出が必要です。申告の期限は、亡くなったことを知った日の翌日から10か月以内です。

自社株の評価や保険・退職金の非課税枠を入れて、ご家族の相続税の目安を一緒に計算します。初回のご相談は無料です。

早見表の前に集めておく数字

次の数字を1枚に並べてから早見表を見ると、目安がずれにくくなります。

  1. 財産を書き出す

    預金・自社株・土地建物・会社への貸付金などを並べます。

  2. 評価額にそろえる

    自社株は国税庁のルール、土地は路線価等で評価します。

  3. 保険・退職金を足す

    非課税枠を引いた後の額を足し、贈与の加算分も足します。

  4. 債務を引いて表を見る

    借入と葬式費用を引いた額で、早見表の行を選びます。

自社株の評価額がまだ分からない場合は、まず決算書の純資産の額を仮に入れて、大きさをつかむ方法もあります。正確な評価は税理士にご確認ください。

よくある質問

早見表の「財産の合計」には、生命保険金を入れますか？

入れる場合は、「500万円×法定相続人の数」の非課税枠を引いた後の額を足します。相続税かんたん試算では、受け取る額をそのまま入れれば、枠はツールが引きます。

早見表で0なら、申告はしなくてよいですか？

特例を使う前の課税価格の合計が基礎控除以下なら、申告は不要です。小規模宅地等の特例を使って基礎控除以下になる場合や、配偶者の税額軽減で税額がゼロになる場合は、申告が必要です。

生前贈与は、何年分を足せばよいですか？

2026年12月31日までに亡くなった場合は、原則として亡くなる前3年以内の贈与です。2027年以後は段階的に延び、2031年1月1日以後は7年以内になります。
