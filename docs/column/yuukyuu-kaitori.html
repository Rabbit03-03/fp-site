退職時の有給休暇の買取りはできる？未消化分の扱い・時効2年・税と社会保険・規程の書き方

公開：2026年11月19日更新：2026年11月19日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 有給休暇の買取りは原則できません。退職や時効で消える分、法定を上回る分は例外とされています。
  • 買取りのお金が退職所得か給与所得かは、国税庁の「退職手当等」の定義に当てはめて判断します。
  • 買い取るかどうか、単価、支払時期は、就業規則や退職金規程に書いておくと揉めにくくなります。

社員が辞めるとき、「残っている有給を買い取ってほしい」と言われることがあります。

買い取ってよいのか、払ったお金は税金や社会保険でどう扱うのか。公式の案内で確認できる範囲で整理します。

有給の買取りは原則できない

年次有給休暇の目的は、仕事から離れて休むことです。お金を払っても、休暇を与えたことにはなりません。

  • 法定の有給休暇を買い上げることは違法とされています。
  • 買上げを予約して、請求できる日数を減らしたり、請求された日数を与えなかったりすることはできません。

「毎年残った分は会社が買い取るので、休まなくてよい」という運用はできない、ということです。

出典：和歌山労働局 よくあるご質問（事業主の方へ）、鹿児島労働局 年次有給休暇Q8、厚生労働省 スタートアップ労働条件

例外とされる3つのケース

休むことを妨げない場合に限り、買上げができるとされています。

ケース理由
退職・解雇で消える分退職日で有給の権利がなくなり、もう休めないため
時効で消える分付与から2年たつと請求できなくなるため
法定日数を超えて与えた分会社が独自に上乗せした休暇のため

例外とされているだけで、会社に買取りの義務があるわけではありません。買い取るかどうかは会社の判断で、だからこそ規程で決めておくことが大切です。

なお、退職日までに残りの有給をまとめて請求された場合、会社は時季変更権を使えず、取得を認めるほかないとされています。引継ぎの日程は、退職の申し出の段階で本人と話し合っておきましょう。

出典：長野労働局 労働条件ハンドブック（年次有給休暇）、厚生労働省 確かめよう労働条件

年5日の取得義務と時効2年

買取りを考える前に、在職中のルールを確認しておきます。

付与日数6か月継続勤務・出勤率8割以上で10日。以後増えて、6年6か月以上で20日
年5日の取得義務年10日以上付与される人（管理監督者を含む）に、付与日から1年以内に5日を取得させる
罰則年5日の義務の違反は30万円以下の罰金
時効付与日から2年。翌年に繰り越せるのはこのため
管理簿年次有給休暇管理簿を作り、その期間中と期間満了後3年間保存する

年5日は、買取りで代えることはできません。退職する人についても、在職中の年5日は守る必要があります。

出典：厚生労働省 年次有給休暇制度の概要等、厚生労働省 年5日の年次有給休暇の確実な取得 わかりやすい解説、厚生労働省 スタートアップ労働条件

退職金と有給の精算をあわせて、退職時にいくら必要になるかを一緒に整理します。

買取りのお金の所得区分

所得税では、退職時に払うお金が「退職所得」になるか「給与所得」になるかで、源泉徴収の方法が変わります。

国税庁の通達では、退職手当等を次のように定めています。

退職所得になるもの給与所得になるもの
考え方本来退職しなかったら払われなかったもので、退職したことに基因して一時に払われる給与退職時や退職後に払っても、計算基準などからみて、勤務を続ける人の賞与などと同じ性質のもの
源泉徴収退職所得の受給に関する申告書があれば退職所得控除を使って計算。なければ支払額の20.42%通常の給与・賞与と同じく源泉徴収し、年末調整の対象

有給の買取りそのものについて、国税庁が所得区分を示した質疑応答は、この記事の執筆時点で確認できませんでした。そのため、上の定義に当てはめて判断することになります。

  • 退職で消える未消化分を、退職を理由に一度だけ買い取る場合は、定義の「退職したことに基因して一時に支払われる」に近い形です。
  • 時効分や法定超の分を、在職中の社員にも同じ基準で定期的に買い取っている場合は、「勤務を続ける人と同じ性質」に近い形です。

どちらに当たるかで源泉徴収票の種類も変わります。実際に払う前に、税務署か顧問税理士に確認してください。退職所得の計算は退職所得控除の記事で解説しています。

出典：国税庁 所得税基本通達30-1、国税庁 No.2725 退職所得となるもの、国税庁 No.2732 退職手当等に対する源泉徴収

社会保険料の扱い

健康保険・厚生年金の保険料は、毎月の報酬（標準報酬月額）と賞与（標準賞与額）にかかります。

日本年金機構の事例集では、退職手当は労働の対償として受けるものではないとして、「報酬等」に当たらないものに挙げられています。ただし、毎月の給与や賞与に上乗せして前払いする退職手当は「報酬等」に当たるとされています。

払い方日本年金機構の案内
退職手当報酬等に当たらない
退職手当の前払い（毎月の給与・賞与に上乗せ）報酬等に当たる
有給の買取り公式の案内で直接の記載は確認できませんでした

有給の買取りが退職手当として扱えるかは、払い方や規程の書き方で変わり得ます。賞与に当たる場合は賞与支払届が必要になることもあるため、年金事務所や加入している健康保険組合に事前に確認しておくと安心です。

出典：日本年金機構 厚生年金保険の保険料、日本年金機構 標準報酬月額の定時決定及び随時改定の事務取扱いに関する事例集

規程に書いておくこと

休暇に関する事項は、就業規則に必ず書く事項です。買取りをするなら、次の点を書いておくと、退職のたびに判断がぶれません。

  1. 対象

    退職時の未消化分だけか、時効分や法定超の分も含むか。

  2. 単価

    1日あたりいくらで計算するか。上限日数を設けるか。

  3. 支払時期

    最終給与と一緒か、退職金と一緒か。

  4. 位置づけ

    退職金規程の一部として払うのか、給与として払うのか。

「位置づけ」は、前の章の税と社会保険の扱いにつながります。規程と実際の払い方をそろえておくことが大切です。

退職金規程そのものの作り方は従業員の退職金規程の作り方、退職時の社会保険・雇用保険などの期限は社員の退職手続き一覧にまとめています。

規程や制度の整備状況は、無料のPDFチェックシートでも確認できます。

よくある質問

退職する社員から有給の買取りを求められたら、応じる義務はありますか？

買取りは退職で消える分などに限って例外的に認められているもので、会社に買取りの義務があるわけではありません。応じるかどうかは、規程の定めに沿って判断します。

退職日まで残りの有給をまとめて使いたいと言われたら、断れますか？

退職日で有給の権利は消えるため、会社は時季変更権を使えず、取得を認めるほかないとされています。引継ぎの日程は早めに本人と相談しましょう。

買取りのお金は退職所得になりますか？

国税庁の定義では、退職しなかったら払われなかったもので、退職を理由に一時に払う給与が退職手当等です。勤務を続ける人の賞与などと同じ性質のものは給与所得です。有給の買取りに直接触れた公式の質疑応答は確認できなかったため、払う前に税務署か税理士に確認してください。
