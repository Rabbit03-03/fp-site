事業承継の3つの形と、それぞれに必要な資金の準備

公開：2026年9月30日執筆：五十嵐 大輔（AFP）

「いずれは会社を誰かに任せたい。でも、何から始めればいいか分からない」。60代の社長からよく聞くお悩みです。

事業承継には、大きく3つの形があります。形によって、必要なお金も、お金を用意する人も変わります。

この記事で分かること
  1. 事業承継の3つの形
  2. 形ごとに必要なお金
  3. 事業承継税制（納税猶予）のあらまし
  4. 準備の進め方と相談先

事業承継の3つの形

中小企業庁は、事業承継を「親族内承継」「従業員承継」「第三者承継（M&A）」の3つに分けて案内しています。

親族内承継従業員承継M&A
誰が継ぐか子どもなどの親族役員や社員社外の会社や個人
株式の移し方贈与・相続が中心（売買もある）後継者が買い取るのが中心買い手に売る
主に必要なお金贈与税・相続税、他の相続人への代償金株式の買取資金、個人保証の整理売却にかかる費用と税金（社長側）
よいところ所有と経営を一緒に引き継ぎやすい社内を知る人が継ぐので、経営が安定しやすい後継者がいなくても会社を残せる。社長は売却代金を受け取れる
注意点株式が相続人に分散しないようにする後継者の資金力。親族株主の了解相手探しに時間がかかる。条件が合わないこともある

どの形でも、後継者を決めてから引き継ぎが終わるまでには時間がかかります。中小企業庁の事業承継ガイドラインでは、移行期間が3年以上かかる割合が半数を上回り、10年以上かかる割合も少なくないとしています。おおむね60歳ごろには準備を始めるのが望ましい、とも書かれています。

形ごとに必要なお金

親族内承継：自社株の税金と、他の相続人への配慮

社長の持つ自社株を後継者に贈与すれば贈与税、相続で引き継げば相続税の対象になります。業績のよい会社ほど株価が高く、税金も大きくなりがちです。

  • 自社株の評価額と、贈与税・相続税の試算
  • 納税資金をどう用意するか
  • 後継者以外の相続人に渡す財産や代償金

財産の多くが自社株だと、後継者以外の子に渡せる財産が足りなくなることがあります。遺留分の請求は、今は金銭で支払う仕組みです。代償金や遺留分の支払いには、後継者を受取人にした生命保険を使う方法があります。生命保険と相続の記事で解説しています。

後継者と他の相続人との間で、遺留分について合意をしておける「民法の特例」もあります。

従業員承継：株式の買取資金と個人保証

役員や社員が継ぐ場合、後継者が社長から株式を買い取るのが一般的です。株価が高いと、後継者個人ではお金を用意しきれないことがあります。

  • 株式の買取資金をどう用意するか（融資の活用など）
  • 会社の借入に付いている社長の個人保証をどうするか
  • 親族の株主に了解してもらえるか

株式の買い取りや相続税の支払いなど、承継に必要な資金には、日本政策金融公庫などの融資や信用保証の支援策があります。

個人保証は、後継者にとって大きな負担です。「経営者保証に関するガイドライン」の特則では、前の社長と後継者の両方から保証をとる「二重徴求」は原則禁止とされています。後継者の保証についても、金融機関が柔軟に判断することになっています。

M&A：社長の手取りと、退職金との組み合わせ

M&Aでは、お金を払うのは買い手です。社長側で考えるのは「最後にいくら手元に残るか」です。

受け取り方税金の扱い
株式の売却代金譲渡益に約20%（所得税15%・住民税5%）と復興特別所得税。ほかの所得と分けて計算
役員退職金退職所得として、ほかの所得と分けて計算

売却の前に役員退職金を受け取ると、会社のお金が減る分、株式の価格にも影響します。どちらでどれだけ受け取るかで、社長の手取りは変わります。仲介などの手数料もかかります。

退職金の額の考え方は役員退職金の相場の記事、支給の根拠づくりは役員退職金規程の記事で解説しています。

どの形で継ぐか、それぞれいくら必要かを1枚に整理します。まだ後継者が決まっていない段階でもご相談いただけます。

事業承継税制（納税猶予）のあらまし

親族内承継や従業員承継で自社株を引き継ぐとき、一定の要件を満たすと、贈与税・相続税の納税が猶予される制度があります（法人版事業承継税制）。

特例措置一般措置
事前の計画特例承継計画を2027年（令和9年）9月30日までに都道府県に提出不要
対象の贈与・相続2018年1月1日から2027年12月31日まで期限なし
猶予の対象全株式。税額の100%総株式数の3分の2まで。贈与税100%、相続税80%
後継者最大3人1人

あくまで「猶予」です。都道府県知事の認定を受け、その後も要件を守り続ける必要があります。要件を満たさなくなると、猶予された税金と利子税を納めることになります。

後継者が亡くなった場合などには、猶予された税金が免除されます。使えるかどうか、使うべきかは、顧問税理士と一緒に判断してください。

準備の進め方と相談先

中小企業庁の事業承継ガイドラインは、準備を5つのステップに分けています。

  1. 必要性に気づく

    事業承継の準備が必要だと認識します。

  2. 見える化

    経営状況、自社株の評価、個人保証などを把握します。

  3. 磨き上げ

    引き継ぐ前に経営を改善します。

  4. 計画づくり

    事業承継計画をつくる。M&Aなら相手探しに進みます。

  5. 実行

    株式や経営を引き継ぎます。

お金の面では、ステップ2の段階で次の3つを数字にしておくと、どの形を選んでも慌てずにすみます。

  • 自社株の評価額と、贈与税・相続税の目安
  • 社長の退職金の額と、その財源
  • 社長に万一があったときに会社に必要なお金（事業保障の記事）

公的な相談窓口として、全国47都道府県に「事業承継・引継ぎ支援センター」があります。事業承継計画づくりの支援や、後継者がいない会社と引き継ぎたい会社のマッチングを行っています。
