社長の退職時期はいつがよい？決算期から考える役員退職金の損金時期と注意点

公開：2026年10月13日更新：2026年10月13日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 役員退職金は、原則として株主総会の決議などで額が確定した事業年度に損金になります。支払った年度に損金経理する方法も認められます。
  • 退職金で赤字になっても、青色申告なら欠損金を10年間繰り越して、翌期以降の所得から差し引けます。
  • 退職の時期は、決算期・定時総会・役員報酬の改定時期・自社株の承継をまとめて決めると、ずれが起きにくくなります。

「何歳で辞めるか」は決めていても、「どの決算期に辞めるか」まで決めている社長は多くありません。

役員退職金は金額が大きいため、どの事業年度の費用になるかで、その期の利益が大きく変わります。決算期から逆算して退職時期を考える方法を説明します。

役員退職金が損金になる時期

国税庁は、役員退職金を損金にする時期を次のように示しています。

区分損金になる事業年度
原則株主総会の決議などで、退職金の額が具体的に確定した事業年度
認められる方法実際に支払った事業年度に損金経理をすれば、その年度
認められない方法額が確定する前の期に、取締役会で内定した額を未払金に計上すること
退職年金支給すべき事業年度（総額を未払計上しても損金にならない）

つまり「決算の直前に辞めて、総会は決算のあと」という場合、原則は総会のある翌期の損金です。今期の費用にしたいなら、今期中に総会で額を決めるか、今期中に支払って損金経理をする必要があります。

金額そのものは、役員退職金規程と、役員退職金の相場と計算方法の記事で説明しています。損金になるのは「適正な額」であることも前提です。

出典：国税庁 No.5208 役員の退職金の損金算入時期

退職金を払う期の利益とのバランス

退職金は1期でまとめて費用になるため、その期が赤字になることがあります。赤字になった場合の扱いは次のとおりです。

項目内容
繰越できる期間青色申告の欠損金は10年間（平成30年4月1日前に開始した事業年度の分は9年間）
中小法人等の控除翌期以降の所得の金額まで差し引ける（国税庁の例：欠損金150万円、所得100万円なら100万円を差し引き、所得は0）
中小法人等以外所得の50％まで（平成30年4月1日以後開始の事業年度）

中小法人等は、資本金1億円以下の普通法人などです（大法人の100％子会社などは除きます）。

欠損金は繰り越せますが、翌期以降に利益が出なければ使い切れません。次のような点を見て、退職する期を選びます。

  • 退職する予定の期の利益の見込みはどのくらいか
  • 翌期以降、後継者の体制で利益を出せる見込みがあるか
  • 退職金を払ったあとの手元資金で、運転資金が足りるか

資金が一度に用意できない場合は、役員退職金の分割払いという方法もあります。損金の時期の考え方が変わるため、あわせてご確認ください。

出典：国税庁 No.5762 青色申告書を提出した事業年度の欠損金の繰越控除

退職金の額と会社の利益の見込みから、どの期に辞めるのがよいか一緒に整理します。

自社株の評価と事業承継

取引相場のない自社株は、会社の規模によって評価の方法が変わります。

会社の規模原則的な評価方法
大会社類似業種比準方式
中会社類似業種比準方式と純資産価額方式の併用
小会社純資産価額方式

類似業種比準方式は「配当・利益・純資産」の3つをもとに計算します。役員退職金を払うと、その期の利益と純資産が減るため、評価が下がることがあります。

評価が下がった時期に、後継者へ株を贈与したり譲ったりすれば、同じ株数でも評価額が小さくなる場合があります。これが「退職金を払う期を事業承継に使う」という考え方です。

  • 評価は決算の数字をもとに計算するため、どの時点の数字が使われるかを確認する
  • 会社の規模や株の持ち方によって、効果の出方は変わる
  • 評価を下げることだけを目的に、退職金の額を決めない

評価のしくみは自社株の評価のしくみの記事で詳しく説明しています。実際の評価額は顧問税理士の計算でご確認ください。

出典：国税庁 No.4638 取引相場のない株式の評価

役員報酬の改定時期との関係

社長が辞めると、後継者の役員報酬を上げることが多くなります。役員報酬（定期同額給与）を損金にするには、改定の時期に決まりがあります。

改定の種類認められる時期・理由
通常の改定事業年度開始の日から3か月を経過する日まで
臨時改定事由役員の職制上の地位の変更、職務内容の重大な変更など
業績悪化改定事由経営状況が著しく悪化したことなどによる減額

定時株主総会は決算から3か月以内に開くことが多く、通常の改定の期限と重なります。定時総会で「社長の退任」「退職金の額」「後継者の新しい報酬」をまとめて決めると、手続きがそろいやすくなります。

期の途中で退任する場合は、地位の変更による臨時改定事由にあたるかを確認します。報酬のしくみは定期同額給与と事前確定届出給与の記事をご覧ください。

出典：国税庁 No.5211 役員に対する給与

会長などで残る場合の注意

社長を退いて会長や非常勤の取締役として残る場合は「分掌変更」になります。法人税基本通達9-2-32は、退職と同じように見られる例として次の3つを挙げています。

例示あわせて見られる点
常勤役員が非常勤役員になった代表権を持ち続ける人や、実質的に経営上主要な地位にある人は除く
取締役が監査役になった経営上主要な地位にある人や、一定の株主要件にあたる人は除く
報酬がおおむね50％以上減った経営上主要な地位にある人は除く
  • 肩書が変わっても、取引先との交渉や資金の決裁を続けていれば、退職とは見られにくい
  • 未払金に計上した退職金は、原則として損金になる退職給与に含まれない
  • 退任後の役割を、議事録や社内の決裁ルールで分かる形にしておく

くわしくは分掌変更で退職金を受け取る条件の記事で説明しています。

出典：国税庁 法人税基本通達9-2-32

退職時期を決める手順

  1. 規程を整える

    役員退職金規程と、退職金の額の目安を決めます。

  2. 利益を見込む

    退職予定の期と翌期以降の利益、手元資金を見ます。

  3. 承継を考える

    後継者の報酬と、自社株を移す時期を合わせて考えます。

  4. 総会で決める

    退任、退職金の額、新しい報酬を決議し、議事録に残します。

退職の数年前から準備すると、退職金の原資づくりや規程の整備に時間をかけられます。

よくある質問

決算の直前に退任し、総会が決算後になった場合、退職金はどの期の損金ですか？

原則は、株主総会の決議などで額が確定した事業年度です。総会が翌期なら翌期の損金になります。前の期に取締役会の内定額を未払計上しても、その期の損金にはなりません。

退職金を払って赤字になったら、損になりますか？

青色申告の法人なら、欠損金を10年間繰り越して翌期以降の所得から差し引けます。ただし翌期以降に利益が出なければ使い切れないため、利益の見込みと合わせて考えます。

後継者の役員報酬は、いつ上げればよいですか？

通常の改定は事業年度開始の日から3か月を経過する日までです。定時総会で退任と同時に決めると、時期がそろいやすくなります。期の途中の地位の変更は、臨時改定事由にあたるかを確認します。
