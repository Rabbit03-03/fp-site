社長が亡くなったら自社株の議決権はどうなる？相続人の共有と権利行使者（会社法106条）

公開：2026年11月3日更新：2026年11月3日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 遺産分割が終わるまで、社長の自社株は相続人みんなの共有になります。共有の株は、権利を行使する人を1人決めて会社に通知しないと、原則として議決権を使えません（会社法106条）。
  • 議決権の使い方は、各相続人の持分の価格の過半数で決めるとする最高裁判決があります。相続人がもめると、株主総会で後継者を取締役に選べない状態になりかねません。
  • いちばんの備えは、遺言で自社株を後継者に渡すと決めておくことです。遺言がなければ、遺産分割を早く進めることが大切です。

中小企業では、社長が自社株の大半を持っていることがよくあります。その社長が急に亡くなると、株は誰のものになり、誰が株主総会で議決権を使うのでしょうか。

答えは「遺産分割が終わるまでは相続人の共有」です。ここに、会社が動けなくなる落とし穴があります。

遺産分割前の自社株は「相続人の共有」

遺言がないまま社長が亡くなると、自社株は法定相続人の共有になります。誰がどの株を受け継ぐかは、相続人全員の遺産分割協議で決めます。

協議がまとまるまでは、「長男が後継者だから長男の株」とはなりません。1株1株を相続人全員で持っている状態です。

たとえば、社長が発行済株式の100％を持ち、相続人が妻と子2人の場合で考えます。

相続人法定相続分単独で過半数？
妻2分の1ちょうど半分で、過半数ではない
長男（後継者）4分の1足りない
次男4分の1足りない

この場合、誰も1人では過半数になりません。長男と次男が組んでも合わせて2分の1で、ちょうど半分です。後継者の長男が過半数を作るには、妻の協力が必要になります。

持分の割合は、遺言で相続分の指定がある場合などで変わることがあります。ご自身のケースは弁護士・司法書士とご確認ください。出典：J-Net21（中小機構）株主・金融機関対応方法

会社法106条：権利行使者を1人決めて通知する

株が共有になったときのルールは、会社法106条に書かれています。要点は次のとおりです。

原則共有者は、権利を行使する人を1人決め、その氏名を会社に通知しなければ、その株の権利を行使できない
例外（ただし書）会社が権利の行使に同意した場合は、この限りでない

つまり、相続人が「権利行使者」を決めて会社に届けるまで、その株で議決権を使うことは原則できません。

例外の「会社の同意」にも注意が必要です。後で説明する平成27年の最高裁判決は、指定と通知がないまま議決権が使われ、その使い方が民法の共有のルールに従っていない場合は、会社が同意しても適法にはならないと判断しました。

出典：e-Gov法令検索 会社法（第106条）

権利行使者の決め方と最高裁判決

相続人全員が賛成しないと決められないのでしょうか。最高裁は、全員一致は必要ないという立場です。

判決確認できる判断の内容
最高裁 平成27年2月19日 第一小法廷判決共有の株の議決権をどう使うかは、株の処分や内容の変更にあたるなどの特段の事情がない限り、各共有者の持分の価格に従い、その過半数で決める
最高裁 平成9年1月28日 第三小法廷判決有限会社の持分を共有する場合に、権利を行使する人は、持分の価格に従いその過半数で決めることができ、全員一致は必要ない

先ほどの例なら、妻と子のどちらか1人が組めば4分の3で過半数です。長男と次男の2人では合わせて2分の1で、過半数になりません。

このように、過半数をどう作れるかは家族の構成と持分で変わります。少数の側の相続人は、話し合いに加わらないまま決められることに不満を持つかもしれません。

どこまでが過半数で決められ、どんな場合が「特段の事情」にあたるかは、個別の事情で判断が分かれます。実際に権利行使者を決めるときは、弁護士・司法書士と確認してください。

出典：裁判所 裁判例検索（平成25(受)650、平成27年2月19日判決）

株主総会が開けず、後継者の役員選任が止まるリスク

取締役は株主総会の決議で選びます（会社法329条1項）。役員を選ぶ決議には、原則として議決権の過半数を持つ株主の出席が必要です（会社法341条、定款で3分の1以上まで下げられます）。

社長が株の大半を持っていた会社で、相続人が権利行使者を決められないと、次のことが起こりえます。

  • 株主総会で定足数がそろわず、後継者を取締役に選べない
  • 社長1人が取締役だった会社では、取締役がいない状態が続く
  • 金融機関や取引先との契約、決算の承認などが進まない

役員が欠けたときは、利害関係人の申立てで、裁判所が一時的に役員の職務を行う人を選ぶ制度もあります（会社法346条2項）。ただ、手続きに時間と費用がかかります。使えるかどうかは弁護士・司法書士とご確認ください。

共同経営者が株を持っている会社の場合は、共同経営者が亡くなったときの株と保険の記事もあわせてご覧ください。

出典：e-Gov法令検索 会社法（第329条、第341条、第346条）

  1. 遺言で株を後継者に

    自社株を誰に渡すか、遺言で決めておきます。

  2. 株価と税を試算

    自社株の評価額と相続税をつかみます。

  3. 家族と共有

    他の相続人への配慮（遺留分）も考えます。

  4. 定款を見直す

    種類株式などの仕組みも専門家と検討します。

中小機構のJ-Net21も、元気なうちに遺言で後継者に株式を割り当てておくことを勧めています。遺言の種類と注意点は社長こそ遺言書をの記事で解説しています。

株を後継者に集めると、ほかの相続人の遺留分が問題になることがあります。生前に贈与する方法や民法の特例は自社株の生前贈与と遺留分の記事、後継者に売る方法は自社株を後継者に売るときの税金の記事をご覧ください。

議決権の制限がある株などの「種類株式」や、株主ごとに扱いを変える「属人的株式」という仕組みもあります。設計には定款変更などが必要です。事業承継の前に見直したい定款の記事も参考に、弁護士・司法書士とご相談ください。

遺言がないまま相続が始まったら、遺産分割をできるだけ早く進めることが何より大切です。自社株の評価のしくみは自社株の相続税評価の記事、相続税の目安は無料の相続税シミュレーションで確認できます。

よくある質問

後継者の長男が、ほかの相続人の同意なしに議決権を使えますか？

遺産分割前の株は相続人の共有です。会社法106条により、権利を行使する人を1人決めて会社に通知しないと、原則として権利を行使できません。最高裁判決では、議決権の使い方は持分の価格の過半数で決めるとされています。長男の持分だけで過半数に届かなければ、ほかの相続人の協力が必要です。

権利行使者は相続人全員の同意で決める必要がありますか？

最高裁は、持分の価格に従いその過半数で決めることができ、全員一致は必要ないと判断しています。ただし、どの場面でも過半数で足りるとは限らないため、具体的には弁護士・司法書士とご確認ください。

社長が今からできるいちばんの備えは何ですか？

遺言で自社株を後継者に渡すと決めておくことです。遺留分への配慮や、種類株式などの仕組みもあわせて、専門家と早めに検討することをおすすめします。
