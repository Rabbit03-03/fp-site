社長が持病で生命保険に入れないときは？告知の注意点と保険以外の会社の備え

公開：2026年11月5日更新：2026年11月5日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 保険に入るときは、健康状態や病歴を事実どおりに告知する義務があります。事実と違う告知をすると、契約が解除され保険金が受け取れないことがあります。
  • 持病があっても、条件付きの契約や、告知項目を減らした「引受基準緩和型」の保険で入れる場合があります。ただし保険料は割高で、保障にも制限があります。
  • 保険だけに頼らず、手元資金、経営セーフティ共済、借入と経営者保証の見直し、後継者との役割分担を組み合わせて備えます。

会社の借入や運転資金に備えるため、社長に生命保険をかけるのは事業保障の基本です。

ところが、持病や健康診断の結果によっては、希望どおりに入れないことがあります。そのときの考え方と、保険以外の備えをまとめました。

まず知っておきたい告知義務

生命保険を申し込むときは、健康状態、病歴、職業などを事実どおりに伝える義務があります。これを告知義務といいます。

「会社のために早く入りたい」と思っても、通院歴を伏せて入るのは避けてください。いざというときに保険金が出ないおそれがあります。

項目内容
告知義務違反があると故意または重大な過失で事実と違う告知をすると、契約や特約が解除され、保険金・給付金を受け取れないことがあります。
解除できる期間約款では、責任開始日から2年以内が一般的です。ただし2年以内に支払事由が起きていれば、2年を過ぎても解除されることがあります。
特に重大な場合詐欺による取消しとなり、2年を過ぎた契約でも保険金が支払われないことがあります。
告知を忘れていたら保険会社に連絡し、告知をし直します。

健康診断で再検査を指摘された、薬を飲んでいる、といったことも告知の対象になりえます。告知書の質問をよく読み、分からないことは保険会社に確認します。

営業職員などから告知を妨げられた場合や、告知しないよう勧められた場合は、解除の対象から除かれます。告知しなかった内容と保険金の支払い理由に因果関係がない場合は、保険金を受け取れます。出典：生命保険文化センター 病歴があったのに告知するのを忘れていたら？

持病があっても入れる可能性がある保険

健康状態によっては、通常の保険でも条件付きで入れることがあります。軽い症状や、完治して一定期間たっている病気なら、条件なしで入れることもあります。

入り方内容
特別保険料通常より高い保険料を払って契約します。
保険金の削減契約から一定期間（5年以内）に病気で亡くなると、死亡保険金が減額されます。
引受基準緩和型告知項目を3〜5項目程度に絞った保険です。定期保険、終身保険、医療保険などがあります。
無選択型告知も医師の診査もいらない保険です。終身保険などを扱う会社があります。

引受基準緩和型や無選択型は入りやすい一方で、事業保障としては物足りないことがあります。

よいところ

  • 通常の保険に入れなかった人も入れる場合がある
  • 告知の項目が少ない

注意点

  • 通常の保険より保険料が割高
  • 死亡保険金の上限が低い傾向（緩和型で1,500万円程度、無選択型で500万円程度）
  • 契約から一定期間は、病気による死亡保険金が減ることが一般的

借入が数千万円ある会社では、緩和型の保険だけで返済まで賄うのは難しいことが多いです。必要な額は必要保障額の無料計算ツールで確かめ、足りない分を次の章の備えで補います。

生命保険文化センターは、健康に不安がある場合も、まず通常の生命保険に入れるかを確認することが大切だとしています。上限額などは一般的な目安で、会社や商品によって異なります。出典：生命保険文化センター 健康上問題があると、生命保険は契約できないの？、告知や医師の診査なしで契約できる生命保険とは？

健康状態に不安があっても、会社に必要な額と、保険で備える分・保険以外で備える分を一緒に整理します。

保険以外の4つの備え

備えポイント
1. 手元資金固定費の6か月分から1年分を一つの目安に、少しずつ積み増します。
2. 経営セーフティ共済積み立てながら、急な資金需要には一時貸付金を使えます。
3. 借入と経営者保証団体信用生命保険の有無と、社長の個人保証を確認・見直します。
4. 後継者と役割分担社長でなければ回らない仕事を減らします。

1. 手元資金を厚くする

保険で備えられない分は、会社の預金で持つのが基本です。社長に万一のことがあると、売上が落ちても固定費は出ていきます。立て直しにかかる期間を考えて目標額を決めます。考え方は事業保障の必要保障額の記事で詳しく説明しています。

2. 経営セーフティ共済で積み立てる

中小機構の経営セーフティ共済（中小企業倒産防止共済）は、取引先の倒産に備える制度です。社長の健康状態にかかわらず加入でき、積み立てた掛金は資金の備えにもなります。

加入できる会社引き続き1年以上事業を行っている中小企業者
掛金月5,000円〜20万円。総額800万円まで
解約手当金40か月以上払えば掛金の全額。12か月未満は戻りません
一時貸付金取引先が倒産していなくても、解約手当金の95%の範囲内で借りられます（12か月未満は不可）

一時貸付金は借入なので、返済が必要です。

出典：中小機構 経営セーフティ共済の特徴、経営セーフティ共済 加入のしおり（PDF）

3. 借入の団信と経営者保証を見直す

会社の借入に団体信用生命保険が付いているか、付けられるかは、借入先によって違います。加入に健康状態の告知が必要なこともあるため、借入先に確認します。

社長の個人保証も見直しどころです。金融庁によると、2023年4月から、金融機関は経営者保証を求めるとき、どの部分が十分でないため保証が必要なのか、どう改善すれば保証を外せる可能性が高まるのかを説明することになっています。

  • 法人と個人の一体性の解消
  • 財務基盤の強化
  • 財務状況の適時適切な情報開示

この3つを満たすと見込まれれば、保証を求めない可能性があるとされています。保証が外れれば、社長に万一のことがあっても家族が会社の借金を背負うリスクが減ります。詳しくは経営者保証を外す条件の記事をご覧ください。

ガイドラインは法的な拘束力のない自主的なルールで、保証の要否は各金融機関が判断します。出典：金融庁 事業者向けパンフレット（PDF）

4. 後継者や幹部と役割を分ける

お金の備えと同じくらい大切なのが、社長が動けなくなっても会社が回る体制です。

  • 取引先との窓口を、社長以外にも持たせる
  • 通帳、印鑑、ネットバンキングの権限を整理しておく
  • 借入や保険の一覧を、後継者や家族と共有する

病気で長く休む場合の備えは、社長が病気で働けなくなったときの記事でチェックリストにしています。

保険は「入れるうち」に検討する

生命保険は、健康なうちほど選べる幅が広くなります。持病が見つかってからでは、保険料が上がったり、希望の額で入れなかったりすることがあります。

  • 健康診断で再検査を指摘される前に、必要な額を決めておく
  • 借入が増えたときは、保障が足りているかをすぐ確認する
  • 今の保険は、入り直すより残す方がよい場合がある。解約の前に、同じ条件で入れるかを確かめる

会社と家族の両方でいくら必要かは、社長の生命保険はいくら必要かの記事で整理しています。

よくある質問

健康診断の結果が悪かったことは、告知しないといけませんか？

告知書で質問されている内容は、事実どおりに答える必要があります。故意または重大な過失で事実と違う告知をすると、契約が解除され、保険金を受け取れないことがあります。

引受基準緩和型の保険だけで事業保障は足りますか？

保険料が割高で、死亡保険金の上限も低い傾向があるため、借入が大きい会社では足りないことが多いです。手元資金や経営セーフティ共済などと組み合わせて考えます。

経営セーフティ共済は、社長の健康状態に関係なく入れますか？

経営セーフティ共済は取引先の倒産に備える共済で、加入の条件は引き続き1年以上事業を行っている中小企業者であることなどです。急な資金需要には、解約手当金の95%の範囲内で一時貸付金を借りられます。
