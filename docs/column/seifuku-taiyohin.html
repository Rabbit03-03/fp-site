社員の制服・作業着・貸与品の経理：給与にならない条件と10万・20万・40万円の線引き

公開：2026年11月27日更新：2026年11月27日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 職務の性質上着る制服や、勤務場所だけで着る作業服を支給・貸与しても、給与として課税しなくてよいとされています。私服にもなるスーツは給与です。
  • パソコンなどは会社の物として「貸与」すれば給与課税は不要です。自由に処分できず、使わなくなったら返す決まりなら「貸与」とみてよいとされています。
  • 買った物の経費の入れ方は、10万円未満・20万円未満・中小企業の特例（令和8年4月1日以後の取得は40万円未満、改正前は30万円未満）で分かれます。

社員に制服や作業着を配る。仕事用のパソコンやスマホ、工具を渡す。どれも会社の負担ですが、渡し方によっては社員の「給与」として扱われることがあります。

この記事では、給与になるかどうかの線引きと、買った物を経費にするときの金額の区切りを、国税庁の資料で確認できた範囲で整理します。

制服・作業着が給与にならない条件

国税庁の源泉徴収の手引では、次のように説明されています。

渡す物給与として課税しなくてよいとされる条件
制服その他の身の回り品職務の性質上、制服を着なければならない人に支給または貸与するもの
事務服・作業服など専ら勤務場所だけで着るもの（制服に準じて扱ってよいとされています）

ポイントは「仕事のために着る物かどうか」です。社名入りのユニフォームや、現場でしか使わない作業着・安全靴などは、この考え方に当てはまりやすいと考えられます。

国税庁の資料には、金額の上限は示されていません。迷う物は、顧問の税理士に確認してから決めると安心です。

出典：国税庁「源泉徴収のあらまし・給与所得の源泉徴収事務の手引」Ⅱ 給与所得の範囲（所法9①六、所令21二・三）、所得税基本通達9-8

スーツ代や私服代を出すと給与になる

国税庁の質疑応答事例では、背広など私服としても着られる物を「制服」として支給した場合、非課税の制服等には当たらず、給与として源泉徴収が必要とされています。

会社の負担扱いの目安
社名入りの制服、現場だけで着る作業着給与として課税しなくてよい場合がある
通勤や休日にも着られるスーツ給与として課税
毎月の「被服手当」「スーツ手当」を現金で給与として課税

「仕事で着るから」という理由だけでは足りません。私服として使えるかどうかが分かれ目になります。

ほかの福利厚生で給与にならない物の一覧は、福利厚生で給与課税されないものの一覧にまとめています。

出典：国税庁 質疑応答事例「背広の支給による経済的利益」

制服や手当の出し方を、給与と経費の両面から一緒に整理します。初回相談は無料です。

パソコン・スマホ・工具：貸与と支給

仕事用の道具は、所有権がどちらにあるかで扱いが変わります。国税庁の在宅勤務FAQでは、パソコンなどの事務用品について次のように示されています。

渡し方所有権扱い
貸与会社のまま給与として課税しなくてよい
支給社員に移る現物給与として課税

「支給」という形で配っても、次の両方に当てはまれば「貸与」とみてよいとされています。

  • 社員が自由に処分できない
  • 業務に使わなくなったら返す決まりになっている

このFAQは在宅勤務向けですが、スマホや工具も同じ考え方で整理しておくと分かりやすくなります。在宅勤務手当や通信費の扱いは、在宅勤務手当の記事で解説しています。

出典：国税庁「在宅勤務に係る費用負担等に関するFAQ（源泉所得税関係）」問2・問3

経費の入れ方：10万円・20万円・40万円の線引き

会社が買ったパソコンや工具は、取得価額によって経費にする方法が変わります。金額は「通常1単位として取引される単位ごと」に判定します。

取得価額経費の入れ方主な条件
10万円未満使い始めた年度に全額を損金にできる（消耗品費など）その年度に損金経理する
20万円未満一括償却資産として3年間で損金にできる選んだ資産の合計額を3年で償却
40万円未満（令和8年4月1日以後の取得）中小企業者等の特例で、全額を損金にできる青色申告、従業員400人以下など。年間合計300万円まで
上記以外耐用年数に応じて減価償却

中小企業者等の特例は、令和8年度の税制改正で、上限が30万円未満から40万円未満に上がりました。令和8年3月31日までに取得した物は、改正前の30万円未満で判定します。特例の期限は令和11年3月31日までの取得分です。

貸付けの用に供した資産（主要な事業として行うものを除く）は、これらの対象から外れます。社員に貸与する道具が当たるかどうかは、税理士に確認すると確実です。

なお、40万円未満の特例で損金にした物は、固定資産税の「償却資産の申告」の対象です。10万円未満と20万円未満の一括償却は対象外です。詳しくは償却資産の申告の記事をご覧ください。

出典：国税庁 No.5403 少額の減価償却資産になるかどうかの判定の例示、国税庁 No.5408 中小企業者等の少額減価償却資産の取得価額の損金算入の特例

退職時の返却ルールの作り方

貸与の扱いにするには、「返す決まり」があることが前提です。口約束ではなく、書面で残しておきます。

  1. 規程を作る

    貸与品の範囲、私用の可否、返却の時期を決めます。

  2. 台帳で管理

    誰に何を渡したか、型番や管理番号を記録します。

  3. 受領のサイン

    渡すときに、返却義務を確認する書面をもらいます。

  4. 退職時に回収

    最終出社日までに返してもらい、台帳を消し込みます。

返却されなかった場合の決め方には、労働基準法の制限があります。

  • 「返さなければ一律○万円」のように、あらかじめ賠償額を決めることは禁止されています（第16条）。
  • 賃金は全額払いが原則で、会社が一方的に給与から差し引くことは原則できません（第24条）。

規程には、「実際の損害を確認したうえで話し合う」といった形で定めておくのが無難です。社員の物になってしまった場合の税務上の扱いは、税理士に相談してください。

出典：厚生労働省「確かめよう労働条件」Q&A

よくある質問

制服に金額の上限はありますか？

国税庁の資料には、制服の金額の上限は示されていません。職務の性質上着る物か、専ら勤務場所で着る物かが判断の目安です。

社員にあげたパソコンは給与になりますか？

所有権が社員に移る「支給」は、現物給与として課税されます。社員が自由に処分できず、使わなくなったら返す決まりなら「貸与」とみてよいとされ、給与課税は不要です。

20万円を超えるパソコンは一度に経費にできますか？

青色申告の中小企業者等なら、特例で一度に損金にできる場合があります。令和8年4月1日以後に取得した物は40万円未満が上限です。年間合計300万円までで、償却資産の申告の対象になります。
