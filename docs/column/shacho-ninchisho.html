社長が認知症になったら会社はどうなる？成年後見・任意後見・家族信託と今できる準備

公開：2026年10月6日更新：2026年10月6日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 自社株の多くを持つ社長の判断能力が下がると、株主総会での議決権の行使や役員の選任、会社としての契約が進めにくくなります。
  • 判断能力が下がった後に使えるのは法定後見です。任意後見と家族信託は、元気なうちに契約しておく必要があります。
  • 生命保険の指定代理請求と銀行口座の扱いも、今のうちに家族と確認しておくと安心です。

相続の準備というと「亡くなったとき」を考えがちです。ですが、その前に「判断能力が下がる」時期が来ることもあります。

厚生労働省の資料では、2022年の65歳以上の認知症の人は約443万人、有病率は12.3％と推計されています。社長にとっても、他人事ではありません。

この記事では、社長の判断能力が下がったときに会社とお金に起きること、使える制度の違い、今できる準備を順に整理します。

社長の判断能力が下がると会社に起きること

中小企業では、社長が「株主」と「代表取締役」を兼ねていることがほとんどです。判断能力が下がると、両方の立場で手続きが止まりやすくなります。

場面起きやすいこと
株主として株主総会で議決権を有効に行使できるか問題になります。社長が株の大半を持っていると、決算の承認や役員の選任が決められなくなるおそれがあります。
取締役として後見開始の審判を受けると、民法の委任の終了事由にあたり、取締役の地位を失うと考えられています。新しい取締役を選ぶには株主総会が必要です。
会社の契約融資、不動産、取引先との契約など、社長の署名が前提の手続きが進めにくくなります。
社長個人のお金預金の引き出し、自宅や自社株の売却、贈与などが難しくなります。

特に注意したいのは、株主総会の議決権です。社長が株の大半を持つ会社では、社長の議決権が使えないと、会社の大事なことを誰も決められない状態になりかねません。

取締役の欠格事由から成年被後見人等を外した会社法改正（2021年3月施行）の検討資料で、後見開始の審判は民法653条により委任の終了事由にあたり、取締役の地位を失うと整理されています。出典：法務省 法制審議会 会社法制部会資料22、法務省 会社法の一部を改正する法律の概要、認知症の人数は厚生労働省（認知症およびMCIの高齢者数と有病率の将来推計）

成年後見（法定後見）と任意後見の違い

判断能力が下がった人を支える国の制度が「成年後見制度」です。大きく、法定後見と任意後見の2つがあります。

法定後見任意後見
始めるとき判断能力が下がった後に、家庭裁判所へ申し立てる元気なうちに契約し、判断能力が下がったら家庭裁判所へ申し立てる
支える人家庭裁判所が選ぶ。家族を候補にしても、弁護士などの専門職が選ばれることがある本人が契約で決めた人
任せる範囲判断能力の程度に応じて後見・保佐・補助の3種類代理権の範囲を契約で決める
契約の形契約なし（審判で決まる）公正証書で結ぶ
監督家庭裁判所家庭裁判所が選ぶ任意後見監督人

法定後見で押さえておきたい点は3つです。

  • 申し立てた後の取り下げには、家庭裁判所の許可が必要です。
  • 原則として、本人の判断能力が回復するか、亡くなるまで続きます。
  • 後見人や監督人の報酬は、家庭裁判所が決め、本人の財産から支払います。

後見人の役目は「本人の財産を守ること」です。会社の将来のために思い切った判断をする、という使い方には向きません。

任意後見なら、誰に何を任せるかを自分で決められます。ただし契約できるのは、判断能力があるうちだけです。

出典：法務省 成年後見制度・成年後見登記制度、法務省 成年後見制度Q&A、裁判所 成年後見制度の概要、裁判所 後見開始

自社株や預金を誰がどう管理するか、ご家族と話す前の整理からお手伝いします。

家族信託で自社株の議決権を託す考え方

もう一つの方法が、家族信託（民事信託）です。ここでは一般的な考え方だけを紹介します。

社長が元気なうちに、自社株を後継者などの家族に「信託」します。株の名義と議決権は家族（受託者）に移し、配当などの利益は社長（受益者）が受け取る、という形がよく紹介されます。

役割一般的な例すること
委託者社長自社株を託す
受託者後継者など株を管理し、議決権を行使する
受益者社長配当などの利益を受け取る

社長の判断能力が下がっても、受託者が議決権を使えるため、株主総会が止まりにくくなります。

一方で、次の点は専門家の確認が欠かせません。

  • 定款で株の譲渡に会社の承認が必要か
  • 受益者を誰にするかで、贈与税や相続税の扱いが変わること
  • ほかの相続人の遺留分との関係
  • 信託が終わったとき、株を誰に渡すか

自社株の評価額によって、贈与や相続の負担は大きく変わります。自社株の評価のしくみもあわせてご覧ください。後継者への引き継ぎ方の全体像は事業承継の3つの形で解説しています。

生命保険と銀行口座の確認

生命保険の指定代理請求

保険金や給付金は、原則として受取人本人が請求します。認知症などで本人が請求できないと、お金を受け取れないおそれがあります。

そこで、あらかじめ指定した代理人が請求できるのが「指定代理請求」の特約です。この特約の保険料は不要です。

  • 代理人になれる家族の範囲は、保険会社によって違います。
  • 代理請求できる保険金・給付金の種類も、保険会社によって違います。
  • 代理人を指定していない契約もあります。保険証券で確認しましょう。

受取人を会社にするか家族にするかの考え方は、社長の生命保険の受取人の記事で解説しています。

出典：生命保険文化センター 指定代理請求特約

銀行口座の扱い

全国銀行協会が示した考え方では、本人の判断能力が下がった場合、銀行は親族などに成年後見制度などの利用を促すのが一般的とされています。

成年後見制度を使っていない場合、親族による代理での取引は、医療費や施設の費用など、本人の利益に合うことが明らかな場合に限って応じることが考えられる、という極めて限られた扱いです。

口座確認しておきたいこと
社長個人の口座生活費・医療費をどの口座から払うか。家族が把握しているか
会社の口座社長以外に手続きできる役員がいるか。銀行の届出印や代表者の変更手続き

銀行ごとに対応は異なります。出典：全国銀行協会 金融取引の代理等に関する考え方

今できる準備のチェックリスト

どれも、社長の判断能力があるうちにしかできないことです。

  1. 役員を複数に

    後継者などを取締役に入れ、社長がいなくても動ける体制にします。

  2. 自社株の持ち方

    任意後見や家族信託など、議決権を誰が使うかを決めます。

  3. 保険と口座

    指定代理請求の有無と、口座の一覧を家族と共有します。

  4. 家族と話す

    考えを家族に伝え、遺言書などとあわせて整えます。

家族への伝え方は、社長の家族会議の進め方が参考になります。病気で働けなくなったときの備えは社長が病気で働けなくなったときの記事をご覧ください。

任意後見契約、家族信託、定款の見直しなどの法律判断は、弁護士・司法書士にご相談ください。税金の判断は税理士の確認が必要です。当社は、お金の全体像の整理と、専門家への橋渡しをお手伝いします。

よくある質問

認知症と診断されたら、もう任意後見契約は結べませんか？

任意後見契約は、本人に契約の内容を理解する判断能力があることが前提です。診断の有無だけでは決まらないため、早めに弁護士・司法書士や公証役場に相談してください。

家族を後見人の候補にすれば、家族が選ばれますか？

法定後見では、後見人は家庭裁判所が選びます。家族を候補にしても、弁護士などの専門職が選ばれることがあります。申し立てた後の取り下げには家庭裁判所の許可が必要です。

家族が社長の口座からお金を引き出せますか？

全国銀行協会の考え方では、銀行は成年後見制度などの利用を促すのが一般的とされています。制度を使っていない場合の親族の代理取引は、医療費など本人の利益に合うことが明らかな場合に限られます。対応は銀行ごとに異なります。
