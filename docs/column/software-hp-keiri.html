ホームページ制作費・ソフトウェアは資産か経費か：耐用年数5年・クラウド利用料・少額資産の特例

公開：2026年10月30日更新：2026年10月30日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 会社の紹介や商品のPRが中心のホームページは、内容を更新していく前提なので、制作費は原則として支出した年の経費（損金）にします。
  • ネットショップや予約システムなど、プログラムの機能を作った部分はソフトウェアです。自社で使うソフトウェアは耐用年数5年で減価償却します。
  • ソフトウェアも減価償却資産なので、10万円未満・20万円未満・40万円未満（中小企業者等の特例）の少額資産の扱いが使えます。クラウドの利用料は、使った期間に応じた経費です。

ホームページを作り直した、予約システムを入れた、会計ソフトをクラウドに切り替えた。どれもITへの支出ですが、経理の扱いは同じではありません。

「全部その年の経費」と思っていると、あとで資産に直すよう指摘されることがあります。どこで分かれるのかを、表で整理します。

ホームページ制作費は原則として経費

国税庁はかつて、ホームページの制作費用の取扱いを次のように示していました。

  • ホームページは会社や新商品のPRが目的で、内容が頻繁に更新される。
  • そのため支出の効果が1年以上に及ばないと考えられ、原則として支出した時の損金にする。
  • 内容を更新しないまま1年を超えて使う場合は、繰延資産として使う期間に応じて償却する。
  • 制作費にプログラムの作成費用が含まれる場合、その部分はソフトウェアとして耐用年数5年で償却する。

この説明は現在、国税庁のサイトには載っていません。ただ、考え方そのものは今も維持されていると報じられています。

ホームページの中身扱いの目安
会社案内、サービス紹介、ブログなど更新していくページ支出した年の経費
更新しないまま1年を超えて使うページ繰延資産として、使う期間に応じて償却
ネットショップ、予約、会員ログイン、検索などのプログラム機能ソフトウェア（無形固定資産）

出典：新日本法規 「ホームページの制作費用」の取扱いが国税庁HPから削除（国税庁が公表していた取扱いの内容と、課税当局への取材で取扱いが維持されていることを確認したと紹介）

プログラム機能があればソフトウェア（耐用年数5年）

ソフトウェアは減価償却資産（無形固定資産）です。耐用年数は用途で決まります。

ソフトウェアの種類耐用年数
複写して販売するための原本、研究開発用のもの3年
その他のもの（自社で使う予約システム、ネットショップ、業務システムなど）5年

取得価額に入るのは、ソフトウェア本体の代金だけではありません。

  • 購入の代価と、購入に要した費用
  • 導入時の設定作業や、自社の仕様に合わせるための付随的な修正作業の費用
  • 自社で作った場合は、製作にかかった原材料費、労務費、経費

たとえば予約システム付きのホームページを一括で発注した場合、予約機能の開発費と設定費はソフトウェア、紹介ページのデザインや文章は経費、という分け方になります。

ソフトウェアは、固定資産税の償却資産の申告の対象外です。詳しくは償却資産の申告の記事をご覧ください。出典：国税庁 No.5461 ソフトウエアの取得価額と耐用年数

見積書を見ながら、経費になる部分と資産になる部分の考え方を一緒に整理します。

クラウド利用料（サブスク）の扱い

クラウドの会計ソフトや予約サービスなど、月額・年額で使う料金は、ソフトウェアを買うのではなくサービスの利用料です。使った期間に応じて経費にします。

払い方扱い
月払いその月の経費
年払い（期をまたぐ）原則は期間で按分し、翌期分は前払費用
年払い（短期前払費用の要件を満たす）支払った期の経費にできる

短期前払費用として支払った期の経費にできるのは、支払日から1年以内に受けるサービスの前払いで、毎期同じ処理を続けている場合です。決算前の対策としての使い方は決算前にできる節税の記事で解説しています。

初期設定費やカスタマイズ費が別に請求される場合は、その中身を確認してください。出典：国税庁 法人税基本通達2-2-14（短期の前払費用）

少額の場合の3つの扱い

ソフトウェアも減価償却資産なので、取得価額によっては一度に経費にしたり、短い期間で償却したりできます。金額は、通常1単位として取引される単位ごとに判定します。

少額の減価償却資産一括償却資産中小企業者等の特例
取得価額10万円未満20万円未満40万円未満（令和8年4月1日以後の取得分。それより前は30万円未満）
処理使い始めた期に全額を経費合計額を3年間で均等に償却使い始めた期に全額を経費
対象すべての法人すべての法人青色申告の中小企業者等（常時使用する従業員400人以下）
上限・期限なしなし年300万円まで。令和11年3月31日までに取得し使い始めたもの

特例の300万円は、事業年度が1年未満なら月割りで小さくなります。従業員数の基準は、令和8年4月1日以後の取得分から400人以下（それより前は500人以下）に変わりました。

特例を使うには、取得価額の全額を損金経理し、確定申告書に明細（別表16(7)）を付けます。10万円未満のものや、一括償却資産として処理したものには、この特例は使えません。

出典：国税庁 No.5408 中小企業者等の少額減価償却資産の取得価額の損金算入の特例、国税庁 No.5403 少額の減価償却資産になるかどうかの判定の例示、中小企業庁 少額減価償却資産の特例

見積書と請求書で確認したいこと

  1. 内訳をもらう

    デザイン、原稿、プログラム開発、設定作業を分けて書いてもらいます。

  2. 機能を確かめる

    予約、決済、会員、検索など、プログラムの機能があるかを見ます。

  3. 金額で分ける

    ソフトウェア部分が10万円・20万円・40万円のどこに入るかを確認します。

  4. 使い始めを記録

    公開日や稼働日を残します。経費にできるのは使い始めた期からです。

IT導入補助金などでシステムを入れた場合は、補助金そのものの経理も必要です。補助金・助成金の経理の記事もあわせてご覧ください。

決算書を見ながら、会社と社長個人にお金を残す方法を一緒に考えます。オンラインで60分、初回は無料です。全国どこからでもご利用いただけます。

よくある質問

ホームページのリニューアル費用も経費になりますか？

会社案内やサービス紹介など、更新していくページの制作費は、原則として支出した年の経費です。予約やネットショップなどのプログラム機能を作った部分は、ソフトウェアとして資産にします。

自社で使うソフトウェアの耐用年数は何年ですか？

5年です。複写して販売するための原本や研究開発用のものは3年です。導入時の設定作業や自社仕様に合わせる修正の費用も、取得価額に含めます。

40万円未満のソフトウェアは一度に経費にできますか？

青色申告の中小企業者等（常時使用する従業員400人以下）なら、令和8年4月1日以後に取得して使い始めた40万円未満の資産を、年300万円まで一度に損金にできます。期限は令和11年3月31日までです。
