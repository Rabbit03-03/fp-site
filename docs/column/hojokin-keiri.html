補助金・助成金の経理と課税のタイミング：益金にする時期・圧縮記帳・消費税・資金繰り

公開：2026年10月27日更新：2026年10月27日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 補助金・助成金は、法人税では益金（収益）です。受け取った年の利益が増え、その分の法人税の対象になります。
  • 雇用関係の助成金は、入金の日ではなく「休業や雇用などの事実があった事業年度」に見積もって計上するのが原則です。設備の補助金は圧縮記帳で課税を先送りできます。
  • 消費税は不課税です。多くの補助金は後払いなので、入金までのつなぎ資金を資金繰り表に入れておきます。

「補助金が決まったので、その分は会社のもうけと関係ない」と考えている社長は少なくありません。

実際には、補助金・助成金も法人税の計算では収益として扱われます。いつ計上するかで、決算の数字と納税額が変わります。経理の基本と、資金繰りで気をつける点をまとめます。

補助金・助成金は法人税の益金になる

法人税は「益金から損金を引いた所得」にかかります。国や自治体から受け取る補助金・助成金は、この益金に入ります。

そのため、補助金を受け取った年は、同じ売上でも利益が大きくなります。赤字の会社なら影響は小さくても、黒字の会社では法人税が増えます。

税目補助金・助成金の扱いポイント
法人税益金（収益）計上する時期に注意
法人税（設備の補助金）益金。ただし圧縮記帳ができる課税を先送りする仕組み
消費税不課税売上と同じようには扱わない

決算の直前に補助金の入金や決定が重なると、思っていたより利益が出ることがあります。決算前の対策は決算前にできる節税と、やってはいけない節税で解説しています。

いつ計上するか：法人税基本通達2-1-42

雇用関係の助成金には、計上する時期について国税庁の通達があります。法人税基本通達2-1-42です。

種類計上する事業年度
休業手当・賃金・職業訓練費などの経費を補うため、雇用保険法などの法令に基づいて受ける給付金給付の原因となった休業・就業・職業訓練などの事実があった事業年度。金額が確定していなくても見積もって計上
定年の延長や高年齢者・障害者の雇用の促進などのために、法令に基づいて受ける奨励金など支給決定があった日の属する事業年度

たとえば雇用調整助成金のように休業手当を補う助成金は、休業した事業年度の収益として見積もって計上するのが原則です。入金が翌期になっても、入金の日を基準にはしません。

一方、奨励金のように「決定されるかどうか」が先に分からないものは、支給決定のあった日の事業年度に計上します。

決算をまたぐ助成金は、どちらの区分にあたるかを顧問税理士と確認しておくと安心です。

出典：国税庁 法人税基本通達 第7款 その他の収益等（2-1-42）

社員の資格取得の費用に関する助成金の経理は、社員の資格取得を会社が支援するときの記事でも触れています。中退共の掛金助成は中退共の助成金の記事をご覧ください。

補助金を受け取る年の利益と納税額を、決算前に一緒に見通します。

設備のための補助金は圧縮記帳ができる

機械や建物など、固定資産を買うための国庫補助金等を受けた場合は、圧縮記帳という仕組みを使えます（法人税法42条）。

補助金に一度に法人税がかかると、設備を買う資金が足りなくなります。それを防ぐための制度です。

使える条件

  • 固定資産の取得や改良に充てるための国庫補助金等であること
  • 交付の目的に合った固定資産を取得・改良したこと
  • 事業年度の終わりまでに、補助金の返還が不要と確定していること
  • 補助金を充てた額の範囲で、帳簿価額を損金経理で減らすか、積立金を積み立てること

数字で見るとこうなります

仮に、1,000万円の機械を買い、500万円の補助金を受けた場合です。

圧縮記帳をしない圧縮記帳をする
補助金の益金500万円500万円
圧縮損（損金）0円500万円
受け取った年の所得への影響500万円増える差し引き0円
機械の帳簿価額1,000万円500万円

圧縮記帳をすると、帳簿価額が下がる分、毎年の減価償却費も小さくなります。つまり、税金がなくなるのではなく、耐用年数にわたって少しずつ課税される「先送り」です。

ものづくり補助金など、設備の取得に使う補助金で検討されることが多い仕組みです。対象になるかは補助金の性格によるので、交付要綱を見ながら確認します。

出典：国税庁 法人税基本通達 第2節 国庫補助金等で取得した資産の圧縮記帳、東京国税局 文書回答事例（法人税法42条の概要）

返還の可能性があるときの扱い

補助金には「条件に違反したら返す」といった条件がつくのが普通です。こうした一般的な条件があるだけなら、返還不要が確定しているかどうかの判断には影響しないとされています（法人税基本通達10-2-1）。

  • 交付の条件に違反した場合は返還しなければならない
  • 一定の期間内に相当の収益が生じた場合は返還しなければならない

また、補助金の額が確定し、その通知を受けたものは、返還不要が確定したものにあたるとされています。

事業年度の終わりまでに返還不要が確定していない場合は、すぐに圧縮記帳をせず、特別勘定として経理する仕組みがあります（法人税法43条）。その後、返還不要が確定した年度に、あらためて圧縮記帳の処理をします（法人税法44条）。

実際に返還することになった場合の処理は、補助金の種類や時期によって変わります。返還の連絡があったら、早めに顧問税理士に相談してください。

出典：国税庁 法人税基本通達 10-2-1、国税庁 別表十三（一）の記載の仕方

消費税は不課税

国や地方公共団体からの補助金・助成金は、消費税の課税対象になりません（不課税）。一般的に、何かの対価として受け取るお金ではないからです。

会計ソフトで売上と同じ「課税売上」の区分にすると、消費税の計算がずれます。勘定科目は「雑収入」などにし、税区分は「不課税（対象外）」にします。

出典：国税庁 No.6157 課税の対象とならないもの（不課税）の具体例

入金までのタイムラグと資金繰り

多くの補助金は後払いです。採択されても、先に会社がお金を払い、実績報告と検査が終わってから入金されます。

  1. 申請・採択

    この段階ではまだ入金されません。

  2. 会社が支払う

    設備代などを先に全額払います。

  3. 実績報告

    報告と検査で額が確定します。

  4. 入金

    数か月先になることもあります。

この間は、自己資金か借入れで立て替えます。資金繰りで押さえる点は次のとおりです。

  • 支払い時期と入金時期を、資金繰り表で月ごとに分けて書く
  • 入金が遅れても回るよう、手元資金に余裕を持たせる
  • つなぎ融資を使うなら、採択の段階で金融機関に相談する
  • 入金された年に法人税が増える分も、納税資金として見込む

資金繰り表の作り方は資金繰り表の作り方と見るべき3つの数字で解説しています。

よくある質問

助成金は入金された年に計上すればよいですか？

雇用保険法などに基づき休業手当や賃金などを補う給付金は、休業や就業などの事実があった事業年度に、金額が確定していなくても見積もって計上するのが原則です（法人税基本通達2-1-42）。高年齢者の雇用の促進などのための奨励金は、支給決定があった日の事業年度に計上します。

圧縮記帳をすれば補助金に法人税はかかりませんか？

課税がなくなるわけではありません。帳簿価額が下がる分だけ将来の減価償却費が小さくなり、耐用年数にわたって課税される「先送り」の仕組みです。

補助金に消費税はかかりますか？

国や地方公共団体からの補助金・助成金は、一般的に対価として受け取るものではないため、消費税の課税対象になりません（不課税）。
