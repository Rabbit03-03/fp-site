奨学金の代理返還とは？会社が社員の奨学金を返す制度の仕組み・税と社会保険・規程の作り方

公開：2026年10月18日更新：2026年10月18日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 会社が社員の奨学金を、日本学生支援機構（JASSO）に直接送金して返す制度です。2021年4月から直接送金ができるようになりました。
  • 会社は給与として損金算入できます。社員は、役員などを除き、所得税の課税対象とならない取扱いになり得ます。
  • 給与とは別に直接送金すれば、社会保険料の算定の基となる「報酬」に含まれません。給与に代えて送金すると報酬に含まれます。

奨学金を返しながら働く若手社員は少なくありません。毎月の返済は、手取りを確実に減らします。

その返済を会社が肩代わりできる国の仕組みが「代理返還（企業等の奨学金返還支援）」です。仕組みと税金、社会保険、規程の作り方を順に説明します。

代理返還の仕組み

会社が、社員の奨学金の返還残額の一部または全部を、社員に代わってJASSOに直接送金します。

手当として社員に払う代理返還（JASSOへ直接送金）
お金の流れ会社 → 社員 → JASSO会社 → JASSO
返済に使われたかはっきりしないはっきりしている
社員の所得税給与として課税一定の場合、課税対象とならない取扱い
社会保険料報酬に含まれる給与と別なら報酬に含まれない

対象はJASSOの貸与奨学金（第一種・第二種）です。支援の対象は、原則として会社が直接雇用している人です。

  • 全額でも一部でも支援できます。金額は会社が決めます。
  • アルバイトなどを対象に含めるかは、会社に委ねられています。
  • 返還期限猶予中や減額返還中の人は、原則としてそのままでは支援できません。本人がJASSOに短縮の願出をする必要があります。

出典：日本学生支援機構 企業等の奨学金返還支援（代理返還）制度、同 Q&A（PDF）

税金と社会保険料の扱い

項目扱い
会社の法人税給与として損金算入できる
社員の所得税「学資に充てるため給付される金品」として、所得税の課税対象とならない取扱いになり得る
社会保険料給与とは別に直接送金すれば、原則として標準報酬月額の算定の基となる報酬に含めない

所得税で気をつけたいこと

国税庁の質疑応答では、奨学金が学資に充てられ、給付がその返済にだけ充てられる場合は、学資金として扱ってよいとされています。ただし、給与課税を逃れる目的の給付は除かれます。

  • 役員への支援は、課税対象とならない取扱いの対象外とされています。
  • 個人事業主ご本人の奨学金は、使用人ではないため損金算入できないと考えられます。
  • 個別の判断は、税務署や税理士に確認してください。

社会保険料で気をつけたいこと

厚生労働省の事例集では、扱いが次の3通りに分かれています。

払い方報酬に含まれるか
給与とは別に、会社がJASSOに直接送金含まれない
返還金を社員に支給する含まれる
給与規程などに基づき、給与に代えて直接送金含まれる

「給料を減らして、その分を返還に回す」形は、社会保険料の面で効果がありません。上乗せの支援として設計するのが基本です。

出典：国税庁 質疑応答事例「奨学金の返済に充てるための給付は『学資に充てるため給付される金品』に該当するか」、日本年金機構 標準報酬月額の定時決定及び随時改定の事務取扱いに関する事例集（PDF）、ミラサポplus（中小企業庁）

給与として課税されない福利厚生はほかにもあります。福利厚生の一覧記事もあわせてご覧ください。

代理返還を入れたとき、会社と社員の手取りがどう変わるかを一緒に試算します。

賃上げ促進税制との関係

代理返還の金額は給与として扱われるため、中小企業向け賃上げ促進税制の「給与等の支給額」に該当し得ます。

要件を満たせば、雇用者全体の給与等支給額の増加額の一定割合を、法人税から差し引ける可能性があります。控除率や上限は要件によって変わるため、詳しくは賃上げ促進税制の記事をご覧ください。

要件や計算の流れは賃上げ促進税制の記事で解説しています。

「対象となり得る」という扱いです。実際に使えるかは、決算期ごとの要件で判断します。出典：ミラサポplus（中小企業庁）、日本学生支援機構 Q&A（PDF）

申込みと送金の流れ

  1. 利用申請

    JASSOに電話またはFAXで申請します。

  2. 専用ページ

    2週間以内を目途に、ログインIDなどが郵送されます。

  3. 支援情報の登録

    対象の社員と支援額を、専用ページで登録します。

  4. 送金

    口座振替か払込取扱票で、JASSOに送金します。

口座振替払込取扱票
引き落とし・依頼毎月6日に引き落とし（土日祝は翌営業日）原則、月初から月中旬までに専用ページで依頼
手数料1件135円（税込）、会社負担ゆうちょ銀行は1件30円、コンビニは所定の手数料
注意登録できる支援期間は1年以内。毎年再登録が必要割賦額未満の支援は原則できない

社員の休職や退職で、支援を中断・再開することもできます。会社からの送金が止まると、社員の口座からの引き落としに自動で戻ります。

スケジュールや書類は変わることがあります。申込み前にJASSOのページで最新の案内をご確認ください。出典：日本学生支援機構 企業等の皆様へ、同 Q&A（PDF）

採用・定着の効果と規程の作り方

採用・定着の効果

  • 求人票や説明会で「奨学金返還支援あり」と示せます。
  • 希望すれば、JASSOのホームページで会社名と取組が紹介される場合があります。
  • 勤続に応じて支援する設計にすれば、若手の定着策になります。

定着策としては、退職金制度との組み合わせも考えられます。社員の定着率を上げる退職金制度の記事で解説しています。

規程に書いておきたいこと

JASSOのQ&Aには規程のひな形はありません。社内で公平に運用するため、次の項目を決めて文書にしておくと安心です。

項目決めておくこと
対象者正社員のみか、勤続何年からか。役員は対象外とする
支援額月額の上限、総額の上限、全額か一部か
支援期間何年間か、在籍中に限るか
支払方法給与とは別に、会社がJASSOへ直接送金すること
中断・終了休職・退職したときの扱い
申請手続社員が出す書類、毎年の確認方法

「給与に代えて送金する」と読める書き方は、社会保険料の面で報酬に含まれる原因になります。上乗せの支援であることがはっきり分かる書き方にしましょう。

規程づくりの考え方は、従業員の退職金規程の作り方も参考になります。

従業員の人数と給与から、御社に合う退職金・福利厚生の組み合わせを一緒に考えます。オンラインで60分、初回は無料です。全国どこからでもご利用いただけます。

よくある質問

奨学金手当として社員に現金で払うのと、何が違いますか？

社員に払うと、返済に使われたかがはっきりしないため、給与として所得税の対象になり、社会保険料の報酬にも含まれます。会社がJASSOに直接送金すると、一定の場合に所得税の課税対象とならない取扱いになり、給与とは別の送金なら報酬にも含まれません。

社長や役員の奨学金も代理返還できますか？

送金自体はできますが、国税庁によれば役員の学資に充てるための費用は非課税の対象とならないとされています。役員は規程で対象外としておくのが分かりやすいです。

社員が辞めたら、支援はどうなりますか？

休職や退職に合わせて支援を中断・再開できます。会社からの送金が止まると、社員本人の口座からの引き落としに自動で戻ります。
