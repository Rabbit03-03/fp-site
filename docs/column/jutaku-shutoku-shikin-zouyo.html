子や孫のマイホーム資金援助｜住宅取得等資金の贈与税の非課税（最大1,000万円）と期限

公開：2026年11月8日更新：2026年11月8日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 父母や祖父母から子や孫へのマイホーム資金の贈与は、省エネ等住宅なら1,000万円、それ以外は500万円まで贈与税が非課税です。
  • 今の制度は2026年（令和8年）12月31日までの贈与が対象です。2026年11月時点で延長は決まっていません。期限が近づいています。
  • 非課税で受けた分は、相続税の生前贈与加算の対象になりません。ただし、税額がゼロでも贈与税の申告が必要です。

「子どもが家を建てるので、少し援助してやりたい」。社長からよく受けるご相談です。

親や祖父母が住宅資金を出すときは、国の非課税の特例が使えます。ただ、今の制度の期限は2026年12月31日です。要件と注意点を表で整理します。

制度のあらましと期限

正式名は「直系尊属から住宅取得等資金の贈与を受けた場合の贈与税の非課税」です。父母や祖父母（直系尊属）から、自分が住む家の新築・購入・増改築のお金をもらったとき、一定額まで贈与税が非課税になります。

住宅の種類非課税限度額（受け取る人1人あたり）
省エネ等住宅1,000万円
それ以外の住宅500万円

省エネ等住宅とは、次のどれかの基準を満たす住宅です。証明書を申告書に付けて示します。

  • 省エネ：新築は断熱等性能等級5以上かつ一次エネルギー消費量等級6以上
  • 耐震：耐震等級（構造躯体の倒壊等防止）2以上、または免震建築物
  • バリアフリー：高齢者等配慮対策等級（専用部分）3以上

対象は2024年1月1日から2026年12月31日までの贈与です。贈与の日は、お金を渡した日です。年内に援助するなら、12月31日までに振り込みを終える必要があります。

国土交通省は令和9年度の税制改正要望で、この非課税措置について「所要の措置」を求めています。延長されるかどうかは、例年12月に公表される税制改正大綱で分かります。2026年11月時点では決まっていません。

中古住宅の省エネ等基準や、一定の経過措置もあります。過去（2009年〜2023年）にこの非課税の適用を受けた人は、原則として使えません。出典：国税庁 No.4508、財務省 令和9年度税制改正要望（国土交通省）

受け取る人（子・孫）の要件

関係贈与した人の直系卑属（子や孫）。配偶者の父母からの贈与は、養子縁組をしていなければ対象外
年齢贈与を受けた年の1月1日に18歳以上
所得贈与を受けた年の合計所得金額が2,000万円以下（床面積40㎡以上50㎡未満の住宅は1,000万円以下）
取引の相手配偶者や親族など特別な関係のある人から買う、またはその人に工事を頼む場合は対象外
住所贈与のときに国内に住所がある（一定の例外あり）

限度額は「もらう人1人あたり」です。父と母の両方から受けても、合計で限度額までです。

社長の場合、気をつけたいのは「取引の相手」です。社長本人や親族から家を買う、親族が経営する工務店に頼む、という形は特例の対象外になることがあります。

住宅の要件と住み始める期限

場所国内の住宅
床面積登記簿上の床面積（マンションは専有部分）40㎡以上240㎡以下で、半分以上が自分の居住用
中古住宅1982年（昭和57年）1月1日以後に建てられたもの、または耐震基準に合うことの証明があるもの
増改築工事費100万円以上で、証明書類があるもの
期限贈与の翌年3月15日までに取得し、住み始める（またはその後すぐ住むことが確実）

翌年3月15日までに住み始められず、その年の12月31日までにも住まなかった場合は、原則として特例は使えません。修正申告が必要になります。

2026年中に贈与するなら、2027年3月15日までに引き渡しと入居を終える段取りが必要です。工期が延びやすい注文住宅は、早めに工務店と確認しましょう。

暦年贈与・相続時精算課税との併用

非課税の特例は、ほかの贈与の制度と組み合わせて使えます。非課税で使い切れなかった分に、次のどちらかを適用します。

暦年課税と併用相続時精算課税と併用
上乗せできる額基礎控除110万円基礎控除110万円＋特別控除2,500万円
省エネ等住宅の場合の合計1,110万円3,610万円
相続時の扱い110万円分は生前贈与加算の対象になり得る基礎控除を超えた分は相続財産に加算

相続時精算課税は、ふつうは贈与する人が60歳以上である必要があります。住宅取得等資金の場合は特例があり、60歳未満の親からの贈与でも選べます（同じく2026年12月31日までの贈与が対象）。

相続時精算課税は一度選ぶと、その親からの贈与は暦年課税に戻せません。社長の相続全体を見て決めましょう。違いは暦年贈与と相続時精算課税の使い分けの記事で詳しく解説しています。

出典：国税庁「住宅取得等資金の贈与を受けた場合の贈与税の非課税」等のあらまし、国税庁 No.4508

申告と相続税への影響

税額がゼロでも申告が必要

特例を使うには、贈与を受けた翌年の2月1日から3月15日までに贈与税の申告をします。申告書に特例を受ける旨を書き、戸籍謄本や売買・請負契約書の写しなどを付けます。非課税で税額がゼロになる場合でも、申告しなければ特例は受けられません。

非課税分は生前贈与加算の対象外

亡くなる前の一定期間の暦年贈与は、相続財産に足し戻されます（生前贈与加算）。この期間は2024年の改正で3年から7年へ、段階的に延びています。

一方、この特例で非課税になった金額は、相続税の課税価格に加算する必要がありません。高齢の社長でも、足し戻しを気にせず渡せるのが大きな特長です。

贈与の種類生前贈与加算
住宅取得等資金の非課税分対象外
暦年贈与（110万円以内も含む）相続人などが受けたものは対象になり得る

ご夫婦間の自宅の贈与には、別の特例（おしどり贈与）があります。おしどり贈与の記事もあわせてご覧ください。いまの財産で相続税がどのくらいになるかは、相続税の無料シミュレーションで目安を確認できます。

出典：国税庁 No.4508 Q&A（Q5・Q6）、国税庁 No.4161 贈与財産の加算と税額控除

よくある質問

2027年以降に贈与しても使えますか？

今の制度は2026年12月31日までの贈与が対象です。2026年11月時点で延長は決まっていません。延長の有無は、例年12月に公表される税制改正大綱で示されます。

妻の両親から援助を受けても使えますか？

対象は直系尊属からの贈与です。配偶者の父母は、養子縁組をしていなければ直系尊属にあたらないため対象外です。

非課税の範囲内なら申告しなくてもよいですか？

申告が必要です。贈与を受けた翌年の2月1日から3月15日までに、特例を受ける旨を書いた贈与税の申告書と必要書類を出してはじめて適用されます。
