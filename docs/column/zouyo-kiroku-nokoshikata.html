生前贈与の記録の残し方：名義預金と言われないための贈与契約書・振込・通帳管理

公開：2026年11月8日更新：2026年11月8日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 贈与は「あげます」「もらいます」の合意で成り立つ契約です（民法549条）。もらう人が知らない積立は、贈与と見られにくくなります。
  • 記録は「贈与契約書」「振込の記録」「もらった人が通帳と印鑑を管理していること」の3点セットで残します。
  • 1年間にもらった額が110万円を超えたら、もらった人が翌年2月1日から3月15日までに贈与税の申告をします。相続時精算課税を選ぶときは届出書が必要です。

子や孫のためにと、毎年少しずつお金を移している社長は多いと思います。

ただ、記録がないまま続けると、相続のときに「これは贈与ではなく、社長の預金（名義預金）では」と見られることがあります。この記事では、あとから説明できる記録の残し方をまとめます。

贈与は「あげる・もらう」の合意で成り立つ

民法549条は、贈与を次のように定めています。

「贈与は、当事者の一方がある財産を無償で相手方に与える意思を表示し、相手方が受諾をすることによって、その効力を生ずる。」

つまり、あげる人の「あげます」と、もらう人の「もらいます」がそろって、はじめて贈与になります。

贈与と説明しやすい名義預金と見られやすい
もらう人の認識もらったことを知っている口座があることを知らない
書面年ごとに贈与契約書がある何も残っていない
お金の動き社長の口座から本人の口座へ振込社長が現金で入金、出どころが分からない
通帳・印鑑・カードもらった人が持っている社長や配偶者が保管している
使い道本人が引き出したり運用したりしている一度も動いていない

名義預金そのものの考え方や、相続税の調査での見られ方は、名義預金とは？の記事と相続税の税務調査で見られやすい社長の財産で詳しく説明しています。

民法550条では、書面によらない贈与は、まだ渡していない部分について各当事者が解除できるとされています。書面にしておくと、約束の内容がはっきりします。出典：e-Gov法令検索 民法（第549条・第550条）

贈与契約書に書く項目

贈与契約書に決まった書式はありません。次の項目がそろっていれば、あとから内容を説明できます。

項目書き方の例
あげる人・もらう人氏名と住所。もらう人が未成年なら親権者も記入
贈与する財産現金○○円、または株式○株など、具体的に
渡す日と方法○年○月○日までに、もらう人名義の○○銀行○○支店の口座へ振込
契約した日実際に署名した日付
署名・押印あげる人ともらう人が、それぞれ自分で署名
  • 契約書は贈与のたびに作ります。毎年なら毎年1通です。
  • 署名は本人の自筆がよいです。社長がまとめて全員分を書くと、合意があったことの説明が弱くなります。
  • 2通作って、あげる人ともらう人が1通ずつ保管します。

お金は振込で渡し、通帳と印鑑は本人が持つ

契約書があっても、お金の動きや管理が伴っていないと、贈与と説明しにくくなります。

やること理由
社長の口座から振込で渡すいつ、誰から誰へ、いくら動いたかが通帳に残ります。現金の手渡しは記録が残りません。
口座は本人が開くもらう人が自分の口座として使っていることを示せます。
通帳・印鑑・キャッシュカードは本人が持つお金を自由に使えるのが誰かが、贈与かどうかの大事な点になります。
本人が使う・運用する生活費や学費、投資など、本人の判断で動かした記録が残ります。

孫が小さいうちは、親権者（子の親）が管理するのが自然です。その場合も、社長自身が通帳を持たないようにします。

今ある家族名義の口座が、贈与として説明できる状態か一緒に確認します。

110万円を超えたら贈与税の申告

暦年課税では、1月1日から12月31日までの1年間にもらった財産の合計が110万円（基礎控除）を超えると、もらった人が贈与税の申告をします。

申告する人もらった人（子や孫）
基準1年間にもらった合計が110万円を超えるとき
期限もらった年の翌年2月1日から3月15日まで（申告と納税）
数え方父と母など複数の人からもらったら、全部を合計して判定

申告書の控えも、贈与があったことを示す記録になります。110万円を少し超える額で贈与し、申告して納税する方もいます。申告の控えと納付の記録は、契約書と一緒に保管しておきます。

出典：国税庁 No.4402 贈与税がかかる場合、国税庁 No.4410 複数の人から贈与を受けたとき

相続時精算課税を選ぶときの届出

相続時精算課税は、60歳以上の父母・祖父母などから、18歳以上の子・孫などへの贈与で選べる制度です（年齢はいずれも贈与の年の1月1日時点）。2024年1月1日以後の贈与から、年110万円の基礎控除ができました。

届出書相続時精算課税選択届出書を、もらった人の住所地の税務署へ出す
期限最初に贈与を受けた年の翌年2月1日から3月15日まで
110万円以下の年贈与税の申告は不要。最初の年は届出書だけを出す
110万円を超える年申告が必要。特別控除は累計2,500万円まで
注意一度選ぶと、同じ人からの贈与は暦年課税に戻せない

精算課税でも、110万円以下の年は申告がないぶん記録が残りにくくなります。届出書の控えに加え、毎年の契約書と振込の記録は同じように残しておきます。

出典：国税庁 No.4103 相続時精算課税の選択、国税庁 相続税及び贈与税の税制改正のあらまし、国税庁 改正の概要

なお、暦年課税の贈与は、亡くなる前7年以内（改正前は3年以内）のものが相続財産に加算されます。暦年課税と精算課税のどちらを選ぶか、加算のしくみは社長の生前贈与：暦年贈与と相続時精算課税の使い分けで解説しています。

毎年の記録チェックリスト

  • 贈与契約書を、あげる人ともらう人の自筆署名で作った
  • 社長の口座から、もらう人名義の口座へ振り込んだ
  • 通帳・印鑑・キャッシュカードは、もらう人（または親権者）が持っている
  • 110万円を超えた年は、翌年3月15日までに申告した
  • 精算課税を選んだ場合は、届出書の控えを保管している
  • 契約書・振込の記録・申告書の控えを、年ごとにまとめて保管している

贈与を続けた場合に相続税がどのくらい変わるかは、相続税の無料シミュレーションで目安を確認できます。

よくある質問

110万円以下の贈与でも、契約書は必要ですか？

申告が要らない額でも、相続のときに名義預金と見られないよう、贈与契約書と振込の記録を残しておくと説明しやすくなります。

孫がまだ小さい場合、贈与契約はどうしますか？

親権者（孫の親）がもらう側として契約書に署名し、通帳や印鑑も親権者が管理します。社長自身が通帳を持たないようにします。

相続時精算課税で110万円以下なら、何も出さなくてよいですか？

その年の贈与税の申告は不要ですが、精算課税を選ぶ最初の年は、翌年3月15日までに相続時精算課税選択届出書を税務署に出す必要があります。
