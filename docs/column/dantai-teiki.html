中小企業の福利厚生としての団体保険：総合福祉団体定期保険のしくみ・経理・規程・同意

公開：2026年10月11日更新：2026年10月11日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 総合福祉団体定期保険は、会社の弔慰金規程・死亡退職金規程で決めた支給額の財源を、1年ごとの定期保険で用意する考え方です。
  • 従業員全員を対象にし、受取人を遺族にした定期保険の保険料は、原則として期間の経過に応じて損金になります。役員や部課長など特定の人だけが対象だと、その人への給与になります。
  • 他人を被保険者にする死亡保険には本人の同意が必要です。規程づくり、同意の取り方、遺族への支払い方を先に決めてから加入を検討します。

従業員が在職中に亡くなったとき、会社から遺族に弔慰金や死亡退職金を払う規程を持つ会社は多くあります。

ただ、急な支払いは会社の資金繰りに響きます。その財源として使われるのが、福利厚生の団体保険です。この記事では、国の資料で確認できる範囲で、しくみと経理、規程と同意の考え方を整理します。

団体保険のしくみ

総合福祉団体定期保険は、会社が契約者になり、従業員を被保険者とする、保険期間1年の定期保険です。毎年更新します。

金融庁の旧事務ガイドラインでは、次の2つの部分に分けて整理されています。

主契約特約（ヒューマン・ヴァリュー特約）
目的規程で決めた弔慰金・死亡退職金などの支払い財源人が欠けたことで会社に生じる費用（代わりの人の採用・育成など）への備え
保険金額の考え方規程に基づく支給額が上限主契約の保険金額などが上限
保険金の行き先遺族へ支払う。会社がいったん受け取る場合も、遺族が了知したうえで渡す会社
同意全員の署名・記名押印のある名簿などで確認本人が個別に書面で同意

大事なのは、主契約が「会社の利益のための保険」ではなく、「遺族に払う約束の財源」という位置づけである点です。保険金額は規程の支給額から決めます。

出典：金融庁 事務ガイドライン（保険会社関係）2-4・2-5 団体扱契約等関係、金融庁 団体定期保険の被保険者同意等に関する公表資料。現在の具体的な引受条件や上限額は、保険会社の約款と設計書で確認してください。

保険料の経理

1年ごとの定期保険の保険料は、法人税基本通達9-3-5で扱いが決まっています。保険期間3年以上で解約返戻率の高い保険に適用される9-3-5の2の資産計上ルールは、保険期間1年の契約には当たりません。

受取人・対象者保険料の扱い（法人）
受取人が会社（特約部分など）原則として、期間の経過に応じて損金
受取人が被保険者の遺族で、全員が対象（主契約）原則として、期間の経過に応じて損金
受取人が遺族で、役員・部課長など特定の人だけが対象その人への給与。本人の生命保険料控除の対象になる
  • 「特定の人だけ」に当たるかどうかは、加入資格の決め方で判断が分かれます。対象者の範囲は顧問税理士と確認してください。
  • 役員への給与とされる保険料を会社が毎月おおむね同じ額で負担する場合は、定期同額給与になります。
  • 年払で決算をまたぐときの処理は、顧問税理士と確認してください。

保険金を会社が受け取り、規程に基づいて遺族へ支払った場合の経理は、死亡保険金を受け取ったときの経理で解説しています。

出典：国税庁 法人税基本通達9-3-5・9-3-5の2、国税庁 タックスアンサーNo.5364、No.5364-2

弔慰金規程・死亡退職金規程との関係

団体保険は規程があって初めて設計できます。保険から先に決めると、保険金額の根拠がなくなります。

規程で決めること内容の例
支給の対象正社員、勤続○年以上の契約社員など
支給額業務上・業務外の別、勤続年数や等級ごとの額
受取人の順位配偶者、子、父母などの順番
支給時期と方法申し出から○日以内に振込など
財源保険金を充てること、保険金と支給額の関係

遺族が受け取る側の扱いにも目安があります。弔慰金は、業務上の死亡なら死亡時の普通給与の3年分、業務外なら半年分までが弔慰金として扱われ、超える部分は退職手当金等として相続税の対象です。死亡退職金には「500万円 × 法定相続人の数」の非課税限度額があります。

受取人の順位や支給額の決め方は、従業員の死亡退職金と弔慰金で詳しく書いています。社長や役員の場合は社長の死亡退職金と弔慰金の決め方をご覧ください。

出典：国税庁 タックスアンサーNo.4120 弔慰金、No.4117 死亡退職金

従業員の同意

保険法では、契約者以外の人を被保険者にする死亡保険は、その人の同意がなければ効力が生じないとされています（保険法38条）。団体保険も同じです。

  • 主契約は、全員の署名・記名押印のある名簿などで同意を確認するのが基本です。
  • 会社が受取人になる特約を付ける場合は、本人が個別に書面で同意します。
  • 会社が保険金をいったん受け取るなら、遺族が内容を知ったうえで支払う手順を決めておきます。

同意を取るときは、何のための保険か、遺族にいくら払う規程か、会社が受け取る部分があるかを、書面で分かるように説明します。説明があいまいだと、あとで遺族との行き違いの原因になります。

出典：e-Gov法令検索 保険法、金融庁 事務ガイドライン（保険会社関係）

検討の手順

  1. 規程を確認

    弔慰金・死亡退職金の規程があるか、額は妥当かを見ます。

  2. 対象を決める

    加入資格を合理的な基準で決め、全員を対象にします。

  3. 金額を決める

    規程の支給額から保険金額を決め、保険料を比べます。

  4. 同意と周知

    同意書をそろえ、規程と保険の内容を従業員に知らせます。

よいところ

  • 規程の支給を資金繰りに頼らず実行できる
  • 1年更新で人数や金額を見直しやすい
  • 全員対象なら保険料は原則損金

注意点

  • 掛け捨てで、会社の資金としては貯まらない
  • 規程と保険金額がずれると説明がつかない
  • 同意と周知の手間がかかる

社長に万一のときの会社の資金は、別の考え方が必要です。事業保障の必要保障額の計算方法をご覧ください。福利厚生全体の見直しは給与課税されない福利厚生の一覧が参考になります。手元で整理したい方は無料PDFチェックシートもお使いください。

よくある質問

社長や部長だけを団体保険に入れることはできますか？

入れることはできますが、受取人が遺族で、役員や部課長など特定の人だけを対象にしている場合、保険料はその人への給与になります（法人税基本通達9-3-5）。

弔慰金規程がなくても加入できますか？

主契約は規程で決めた弔慰金・死亡退職金の財源という位置づけで、保険金額は規程の支給額が上限です。まず規程を整えてから検討するのが順番です。

従業員の同意は口頭でもよいですか？

保険法38条で被保険者の同意が必要とされ、団体保険では名簿への署名・記名押印などの書面で確認するのが基本です。会社が受取人になる特約は、本人の個別の書面同意が必要です。
