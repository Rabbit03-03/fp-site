持株会社（ホールディングス）をつくる事業承継：つくり方とメリット・注意点

公開：2026年10月20日更新：2026年10月20日執筆：五十嵐 大輔（AFP）

この記事の要点

  • 持株会社のつくり方は、株式移転・株式交換・会社分割・後継者の会社が買い取る方法の4つが代表的です。目的によって向き不向きがあります。
  • メリットは、事業会社の株を持株会社に集めて、経営と所有を分けやすくなることです。後継者に渡す株も持株会社の株にまとまります。
  • 持株会社の資産の50%以上が株式等だと「株式等保有特定会社」に当たり、自社株の評価は原則として純資産価額方式になります。設計の前に評価と税務の確認が欠かせません。

事業承継の相談で「ホールディングスをつくるといい」と聞いた、という社長は少なくありません。

持株会社は、事業会社の株を持つための会社です。つくり方は1つではなく、選び方で税金や資金の流れが大きく変わります。この記事では全体像を整理します。

持株会社を使った事業承継とは

社長が事業会社の株を直接持つ形から、「社長（または後継者）→ 持株会社 → 事業会社」という形に変えるのが基本です。

いまの形持株会社をつくった形
社長が持つもの事業会社の株持株会社の株
事業会社の株主社長・親族など持株会社
後継者に渡すもの事業会社の株持株会社の株

自社株を贈与・売買・相続で渡す方法そのものは、自社株を後継者に渡す3つの方法で比べています。持株会社は、その前に「株の持ち方」を整える手段と考えると分かりやすくなります。

つくり方は4種類

方法しくみ（会社法の定義の要約）向いている場面
株式移転事業会社の発行済株式の全部を、新しく設立する株式会社に取得させる新しく持株会社をつくり、いまの株主構成をそのまま上に移したい
株式交換事業会社の発行済株式の全部を、既にある会社に取得させるすでにある会社（資産管理会社など）を持株会社にしたい
会社分割事業に関する権利義務の全部または一部を、他の会社や新しく設立する会社に承継させる事業と不動産などを分けたい、事業ごとに子会社にしたい
後継者の会社が買い取る後継者が出資した会社が、社長から事業会社の株を売買で買い取る後継者に経営権を移し、社長は売った代金を受け取りたい

株式移転・株式交換・会社分割は、会社法の組織再編の手続きです。原則として株主総会の特別決議が必要で、債権者への手続きが必要になる場合もあります。

4つ目の買い取りは組織再編ではなく、ふつうの株の売買です。社長には売った代金が入り、譲渡益には申告分離課税（所得税・住民税で20%と復興特別所得税）がかかります。

出典：e-Gov法令検索 会社法（第2条第29号〜第32号、第309条第2項、第767条、第772条）、国税庁 No.1463 株式等を譲渡したときの課税

メリット：経営と所有の分離、株の集約

よいところ

  • 事業会社の株が持株会社に集まり、親族への分散を防ぎやすい
  • 後継者に渡すのは持株会社の株になり、承継の対象が1本にまとまる
  • 持株会社が株主として事業会社を見守り、経営は事業会社の役員に任せる形をつくれる
  • 事業が複数あれば、事業ごとに会社を分けて管理しやすい

気をつけたいところ

  • 会社が1つ増え、決算・申告・維持の費用がかかる
  • 評価のルールが変わり、自社株の評価が上がる場合もある
  • 組織再編や売買には、税務・登記・法務の専門家の関与が必要

「経営と所有の分離」とは、株を持つ人（オーナー家）と、日々の経営をする人を分けて考えることです。親族以外の役員に経営を任せつつ、株はオーナー家が持株会社を通じて持つ、という形が代表例です。

株の集約は、議決権が親族に散らばるのを防ぐ考え方です。定款での備えは事業承継に向けた定款の見直しも合わせてご覧ください。

持株会社が合うかどうかは、会社の株の持ち方と後継者の状況で変わります。まずは現状の整理から一緒に行います。

注意点：株式等保有特定会社と評価方法

持株会社は、資産の多くが事業会社の株になります。そのため、相続税・贈与税の評価で「株式等保有特定会社」に当たりやすい点に注意が必要です。

判定課税時期に、会社の資産（通達で評価した額）の合計のうち、株式・出資・新株予約権付社債の割合が50%以上
評価方法（原則）純資産価額方式
選択できる方法納税義務者の選択で「S1＋S2方式」（株式等以外の部分を類似業種比準方式に準じて評価したS1と、株式等の部分を純資産価額で評価したS2の合計）
資産構成の変更合理的な理由なく、判定を免れるために課税時期前に資産構成を変えたと認められる場合は、その変動はなかったものとして判定

ふつうの会社なら、会社の規模に応じて類似業種比準方式を使えます。株式等保有特定会社に当たると原則の評価方法が変わるため、評価額が想定と大きく違うことがあります。

評価方式の基本は自社株の相続税評価のしくみで説明しています。持株会社をつくる前と後で評価がどう変わるか、試算してから進めるのが安全です。

同族株主以外の株主等が取得した株式の扱い、比準要素数1の会社などとの関係は、通達で別に定められています。出典：国税庁 財産評価基本通達189・189-3、国税庁 No.4638 取引相場のない株式の評価

後継者の会社が買い取るときの資金の流れ

後継者の持株会社が社長から株を買う場合、買い取り資金は金融機関からの借入でまかなうことが多くなります。流れは次のとおりです。

  1. 会社を設立

    後継者が出資して持株会社をつくります。

  2. 借入

    持株会社が金融機関から買い取り資金を借ります。

  3. 株を買い取る

    社長から事業会社の株を時価をもとにした価格で買います。

  4. 配当で返済

    事業会社からの配当を、持株会社の返済にあてます。

持株会社が事業会社の株を100%持ち、配当の計算期間を通じて完全支配関係があれば、受け取る配当は「完全子法人株式等」の配当として、全額が持株会社の益金に算入されません。

ただし、配当は事業会社が税金を払ったあとの利益から出します。返済期間中に業績が落ちると、返済が苦しくなります。借入額と返済計画は、事業会社の利益の見通しから逆算して決めます。

売買価格にも注意が必要です。個人が法人に時価の2分の1未満の価額で資産を譲渡すると、時価で譲渡したものとされます。安く売れば得、とはなりません。

出典：e-Gov法令検索 法人税法（第23条 受取配当等の益金不算入）、国税庁 No.3105 譲渡所得の対象となる資産と課税方法

税務は個別判断が必要

持株会社づくりは、どの方法でも税務の判断が絡みます。主な確認点をまとめます。

  • 株式移転・株式交換・会社分割が、法人税法上の「適格」の要件を満たすか（満たさないと、会社や株主に課税が生じることがある）
  • 持株会社が株式等保有特定会社に当たるか、つくる前後で評価がどう変わるか
  • 買い取りの場合の売買価格（時価）の決め方と、社長の譲渡所得
  • 借入の返済原資となる配当の見通しと、事業会社の資金繰り
  • 事業承継税制を使う予定があるか（使う場合は要件との関係を確認）

同じ「持株会社」でも、会社の財産の中身や株主構成で結果は変わります。具体的な判断は、税理士などの専門家と一緒に進めてください。

社長個人の資産を管理する会社とは目的が違います。個人の資産管理が主な目的なら資産管理会社は必要かをご覧ください。相続税の大まかな額は相続税の無料シミュレーターで確認できます。

適格分割・適格株式交換等・適格株式移転の定義は、法人税法第2条第12号の11・第12号の17・第12号の18にあります。出典：e-Gov法令検索 法人税法

よくある質問

持株会社をつくれば、自社株の評価は必ず下がりますか？

必ず下がるとは限りません。持株会社の資産の50%以上が株式等だと株式等保有特定会社に当たり、評価は原則として純資産価額方式になります。つくる前と後で評価を試算して比べることが大切です。

株式移転と株式交換は何が違いますか？

株式移転は、事業会社の株の全部を新しく設立する会社に取得させる方法です。株式交換は、事業会社の株の全部を既にある会社に取得させる方法です。どちらも原則として株主総会の特別決議が必要です。

後継者の会社が株を買い取るとき、借入はどう返しますか？

事業会社から持株会社への配当を返済にあてるのが一般的です。100%子会社で完全支配関係が続いていれば、受け取る配当は全額が益金に算入されません。ただし配当は事業会社の税引後の利益から出すため、利益の見通しから返済計画を立てます。
