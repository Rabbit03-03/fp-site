会社に必要なお金を3つに分けて足し、預金と今の保障を引きます。考え方は事業保障の必要保障額の記事でくわしく解説しています。

  1. 1借入の返済残高の全額
  2. 2運転資金固定費 × 月数
  3. 3退職金・弔慰金ご遺族へ
  4. 4準備分を引く預金と今の保険

功績倍率は例です。実際は役員退職金規程で決めます。会社が受け取った保険金は原則として益金になり法人税の対象になるため、税金分まで見込むかは顧問税理士とご確認ください。内容は2026年9月時点のものです。

よくある質問

運転資金は何か月分見込めばいいですか？

固定費の6か月分から1年分が一つの目安です。社長がいなくなってから立て直すまでにかかる期間で考えます。

借入が減ったら保険も減らせますか？

必要保障額が下がれば、保障を減らして保険料を下げられることがあります。解約や減額の前に、戻り額や税金への影響を確認しましょう。

どのくらいの頻度で見直せばいいですか？

決算のたびに1回、ほかに借入や役員報酬が変わったときに見直すのがおすすめです。
